# MathGraph 한글 연결

Windows용 한컴오피스 한글과 Python 3.10 이상이 필요합니다.
Python은 https://www.python.org/downloads/windows/ 에서 설치할 수 있습니다.

1. 압축을 풀고 `시작.cmd`를 실행합니다. 처음 실행할 때 이 폴더 안에 Python 실행 환경과 PyPI의 pywin32를 설치합니다.
2. 자동으로 열린 MathGraph에서 로그인하거나 바로 그리기를 선택합니다.
3. 사진을 가져오면 문제와 그림을 인식합니다. 인식에는 기존 MathGraph의 AI 설정을 사용합니다.
4. **한글에 넣기**에서 본문과 그림을 확인하고 **커서 위치에 넣기**를 누릅니다.

문서가 없으면 새 문서를 만듭니다. 하나면 자동으로 선택합니다. 여러 개면 제목과 ‘현재 문서’ 표시를 확인해 고르세요. 같은 파일 이름은 폴더 이름으로 구분합니다.
한글에서 선택 영역을 해제하고 원하는 위치에 커서를 놓아야 합니다.
이미 열려 있는 문서는 자동 저장하거나 닫지 않습니다. 실행 취소는 한글에서 할 수 있습니다.

본문의 수학 표현은 편집 가능한 한글 수식입니다. 그림의 선과 도형은 PNG이며, 그 위의 문자와 숫자는 별도의 한글 수식입니다. 점 이름과 길이값은 10 mm 투명 글상자를 끌어 옮기고, 글자를 두 번 눌러 수식을 편집할 수 있습니다.
기본 글꼴·글자 크기·문단 모양은 현재 커서의 설정을 따릅니다. 조건·보기는 테두리로 묶고, 선택지의 줄바꿈은 유지합니다. 그림 폭은 80/120/150 mm로 선택할 수 있습니다.
분수, 근호, 지수, 첨자, 일반적인 기호를 지원합니다. 변환할 수 없는 수식은 입력 전에 알려 줍니다.
음수나 여러 항의 지수·첨자는 `$x^{-2}$`, `$a_{n+1}$`처럼 중괄호로 묶습니다. 지수 뒤의 덧셈과 분수 뒤의 항이 원래 범위를 벗어나지 않도록 변환합니다.
점·선분 이름의 정체와 변수의 기울임을 구분하며, 평행 관계는 비스듬한 기호로 출력합니다. 그림 바깥의 여백은 줄이고 글자가 선과 겹치지 않도록 배치합니다.
사진이 흐리거나 조건이 빠진 경우에는 확인 사항을 검토해야 입력할 수 있습니다.
‘다음 사진부터 인식 후 바로 넣기’를 켜면, 확인 사항이 없고 그림 생성까지 성공한 다음 사진부터 자동으로 넣습니다. 처음부터 자동으로 넣지 않습니다.

연결 프로그램은 이 PC의 127.0.0.1:18765에서만 실행됩니다. 매번 바뀌는 연결 코드와 등록된 MathGraph 주소를 함께 검사합니다.
코드가 들어 있는 주소는 공유하지 마세요. 종료하려면 연결 프로그램 창에서 Ctrl+C를 누릅니다.
브라우저가 로컬 네트워크 연결을 요청하면 이 기능을 사용할 때 허용해 주세요.
한글이 파일 접근 확인창을 띄우면 넣으려던 MathGraph 그림인지 확인한 뒤 처리해 주세요.
자동화를 허용하는 보안 모듈은 임의로 설치하거나 보안 설정을 끄지 않습니다.

문제 인식 결과가 맞는지는 원본 사진과 비교해 확인해 주세요.
입력 결과를 받지 못했다는 메시지가 나오면 **결과 다시 확인**을 누르세요. 같은 요청은 중복 입력하지 않습니다.
