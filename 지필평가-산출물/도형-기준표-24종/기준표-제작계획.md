# 시험 도형 기준표 24종 제작 계획

## 목표

서로 다른 요소를 한꺼번에 바꾸지 않고, 시험지 도형에서 반복되는 배치 문제를 24개 시안으로 나누어 비교한다. 사용자가 각 시안을 직접 다듬은 뒤 수정 전후의 인쇄 크기와 좌표 차이를 계산하여 `pbj-exam-hwpx`의 도형 규칙으로 반영한다.

## 공통 기준

- 꼭짓점·교점·중점의 검은 동그라미는 표시하지 않고 이름만 둔다.
- 열린 점·닫힌 점처럼 점 모양 자체가 수학적 조건일 때만 점 표식을 사용한다.
- 선 굵기, 점 이름 13pt, 조건식 11pt를 먼저 고정한다.
- 각 시안은 한 가지 핵심 요소만 비교할 수 있게 구성한다.
- GraphA 원본 JSON, 인쇄용 내보내기 JSON, 그림 PNG, 라벨 포함 미리보기 PNG를 함께 보관한다.

## 시안 구성

1. 점 이름 위치 6종: 예각·둔각·직각삼각형, 평행사변형, 오목사각형, 한 직선 위의 세 점
2. 각도 호 6종: 예각·둔각·두 겹 호·두 꼭짓점의 각·대각선 반각·직각에 가까운 큰 각
3. 길이 호 6종: 위·아래·기울어진 변·마주 보는 변·대각선의 두 부분·좁은 공간의 두 길이
4. 교점과 복합 배치 6종: 사각형 대각선, 삼각형 내부 교점, 연장선의 외부 교점, 원의 현, 수선의 발, 평행 표시와 복합 라벨

## 피드백 기록 방식

각 시안은 `P01`부터 `P24`까지 번호를 붙인다. 사용자는 유지·수정·제외 중 하나를 표시하고 필요한 경우 MathGraph에서 직접 라벨과 도형을 옮긴다. 수정본을 받으면 다음 값을 비교한다.

- 점 이름의 꼭짓점 기준 방향과 거리
- 각도 호의 인쇄 반지름과 각도식 중심 위치
- 길이 호의 인쇄 높이·방향·라벨 간격
- 교점 이름의 선 교차점 기준 방향과 거리
- 선·호·글자 사이의 최소 인쇄 여유

## 완료 기준

- 24개 GraphA 원본과 내보내기 그림이 모두 생성된다.
- 모든 꼭짓점·교점의 점 표식이 제거된다.
- 각 시안의 핵심 비교 요소와 초기 수치가 목록으로 정리된다.
- 사용자가 직접 다듬을 수 있는 원본 파일과 한눈에 보는 검토용 자료를 제공한다.
