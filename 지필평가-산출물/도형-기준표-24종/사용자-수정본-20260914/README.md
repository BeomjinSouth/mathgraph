# 사용자 수정본 보존 기록

- 2026-09-14에 전달받은 MathGraph 프로젝트 파일과 이후 직접 수정한 P21 파일까지 19개를 이름과 내용 그대로 보존했다.
- 작업용 `프로젝트` 폴더에는 P01~P13, P15, P19, P20, P22의 사용자 수정본을 반영했다.
- P12 두 파일은 도형 내용이 같고 `savedAt`만 2초 차이였다. 작업용 파일에는 더 늦게 저장된 `(1)` 파일을 사용했다.
- 이전 앱이 길이 치수의 `curvature`를 저장하지 않아 P13·P15에서 해당 값이 빠져 있었다. 작업용 파일에는 기존 기준 곡률만 복원했고, 이 보존 폴더의 사용자 원본은 바꾸지 않았다.
- 전달되지 않은 P14·P16·P17·P18·P21은 기존 작업용 파일을 유지했다.
