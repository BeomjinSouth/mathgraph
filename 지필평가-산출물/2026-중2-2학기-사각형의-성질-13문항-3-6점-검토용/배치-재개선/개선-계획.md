# 각도 호·점 이름·문항 배치 재개선

## 기준과 범위

사용자가 직접 고친 `가독성-개선/학생용-사각형의-성질-가독성-개선-완성-내가수정한거.hwpx`를 수정 기준으로 사용한다. 원본과 직접 수정한 파일을 덮어쓰지 않는다. 13문항·60점·학교 양식은 유지한다.

1. 사용자 수정 전후의 라벨 위치를 실제 HWPX에서 비교하고, 사용자가 옮긴 위치를 새 결과에 보존한다. 새로운 충돌이 생길 때만 이유를 기록하여 최소 조정한다.
2. 각도 글꼴과 각도 호의 크기를 분리한다. 조건 글자는 읽을 수 있는 크기를 유지하되 호의 실제 인쇄 반지름을 작게 줄인다. 3번 길이 표시와 위치는 유지한다.
3. 9번에는 두 대각선의 교점 O를 넣고 본문 각을 BAO·ABO로 표기한다. 기존 BAC·ABD와 같은 각이라는 사실과 교사용 해설도 대조한다.
4. 보기 상자는 문항 바로 아래에 넣고 빈 문단을 추가하지 않는다. 각 보기 문장의 ㄱ·ㄴ·ㄷ·ㄹ 앞에는 공백 한 칸을 둔다.
5. 문항 사이 여유를 각 단에 분산한다. 하단에만 몰린 여백을 없애되 문항·그림·선택지를 나누지 않고 필요한 풀이 공간을 남긴다.
6. 실제 렌더→수치 및 시각 점검→수정의 반복으로 스킬의 기본 생성과 검사도 개선한다. 단순 실행은 Luna, 범위가 작은 보조 조사는 Terra를 사용하고 설계·수정 판단·최종 확인은 메인이 맡는다.

## 완료 증거

수정 전후 비교, 실제 호 반지름(mm), 교점과 각 표기의 대응, 보기 앞 빈 문단0개 및 표지 문자 앞 공백, 단별 문항 시작/끝/하단 여유를 기록한다. 새 최종 HWPX에서 한글 PDF를 출력하고 전 쪽을 직접 확인한다. 독립 검토와 최종 전달 검사를 마쳐야 완료다. 앱 운영 배포와 외부 전송은 범위 밖이다.

## 첫 반복의 관찰과 다음 구현

- 사용자 파일은 라벨30개를 변경했으며,3번의 D 글상자 앵커를 질문 문단으로 옮기고 그림 폭도 약0.9% 조정했다. 따라서 전체 재생성보다 사용자 문서의 문단·개체를 그대로 보존하는 수정 경로를 우선한다.
- 1번에서 기존 인쇄 호 반지름 약7.2mm를2.2mm로 줄여 실제 MathGraph 내보내기를 확인했다. 크롭 비율과 그림 크기는 그대로다. 공통 내보내기에 `--angle-radius-mm`를 추가하여 글자 크기와 독립 조절한다.
- Terra 작업자가 보기 상자 삽입 앞의 실제 빈 문단만 확인 후 제거하고, 보기 기호 앞 한 칸 공백을 넣도록 statement_box를 수정했다. 실제 한글 삽입 검사는 아직 필요하다.
- Luna 작업자가 사용자 수정본의 한글 검증과PDF4쪽 렌더를 완료했고 메인이2~4쪽을 직접 보았다.
- 3쪽 시험 배치안: 2쪽 왼쪽 MC1~3, 오른쪽 MC4~8; 3쪽 왼쪽 MC9·E1·E2, 오른쪽 E3·E4. 실제 출력에서 문항 묶음과 풀이 공간을 확인한다.

## 완료 확인

두 번째 시안에서 위의 3쪽 배치를 확인했다. 호 반지름은 실제 비교 후 3mm로 확정했다. 사용자 라벨 37개와 3번 그림을 보존했고, 단별 하단 여유와 논술형 풀이 공간도 실제 PDF로 측정했다. 보기 삽입의 새 문서 시험과 기본 호·원본 보존·라벨 이동 거부 회귀 검사도 마쳤다. 최종 두 파일의 실제 한글 검사, 전체 쪽 확인, 독립 검토, 전달 검사가 완료됐다. 자세한 근거와 검사 대상 불일치 이력은 `수정-검증-요약.md`에 기록했다.

## 후속 미세 조정

사용자의 인쇄 화면 비교를 새 우선 기준으로 적용했다. 1번과 논술형 4의 3mm 각도 호, 3번의 길이 호는 유지한다. 9번과 논술형 2의 각도 호만 5mm로 키우고, 2번 길이 호는 원시 곡률 대신 인쇄 높이 5mm로 낮춘다. 논술형 2의 두 각도식은 해당 각의 내부 이등분선 부근에서 실제 선·점·다른 라벨과 0.85mm 이상 떨어지는 위치만 허용한다.
