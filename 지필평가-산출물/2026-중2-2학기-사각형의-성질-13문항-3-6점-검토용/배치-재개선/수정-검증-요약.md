# 각도 호와 문항 배치 수정 결과

최종 파일은 `학생용-배치조정-v2.hwpx/pdf`와 `교사용-배치조정-v2.hwpx/pdf`다. 창작한 검토용 시험지이며, 13문항·60점 구성을 유지했다.

## 요구사항별 확인

| 요청 | 실제 반영과 확인 근거 |
|---|---|
| 각도 호 축소 | 호 8개의 인쇄 반지름을 3mm로 조절했다. `보존-배치-v2-검사.json`에 실제 크기를 기록했다. |
| 직접 옮긴 이름 보존 | 사용자 수정본의 라벨 37개에 대해 위치·크기·앵커 역할을 비교하여 모두 보존했음을 확인했다. |
| 3번 유지 | 그림 바이너리, 수동 조정한 폭, 라벨 및 질문 문단으로 옮긴 D의 앵커를 보존했다. |
| 9번의 O·BAO·ABO | 실제 교점 객체 O를 넣었다. 본문·그림·교사용을 직각삼각형 ABO의 관계로 맞췄다. |
| 보기 앞 빈 줄 제거 | 질문 바로 다음 문단에 상자를 넣었다. 최종 구조와 새 삽입 시험에서 확인했다. |
| 기호 앞 공백 | ㄱ·ㄴ·ㄷ·ㄹ 앞에 각각 공백 한 칸을 넣었다. 줄바꿈한 문장도 테두리 안에 들어간다. |
| 하단 여백과 간격 | 표지 포함 4쪽을 3쪽으로 재배치했다. 2쪽의 하단 여유는 왼쪽 12mm, 오른쪽 23.5mm다. |
| 풀이 공간 | 논술형 1~4번에 각각 약 33.7·50.5·83.3·73.1mm의 세로 공간을 배정했다. `단별-공간-검사.json`에 실제 PDF 측정값이 있다. |
| 스킬 반복 개선 | 호 크기 기본값, 보기 삽입, 사용자 좌표 보존 검사를 수정하고 실제로 실행했다. |
| 작업자 분담 | Terra는 작은 조사·보기 삽입 수정·독립 검토를, Luna는 정해진 명령의 실행을 맡았다. 메인은 설계·통합·오류 판단을 맡았다. |

호는 그림 내부 요소여서 한글에서 호만 선택하여 크기를 바꾸기 어려웠다. 이제 내보내기 단계에서 인쇄 mm로 제어한다. 기본값은 3mm이며, 원래 GraphA의 호를 유지할 때는 `--angle-radius-mm source`를 사용한다. 한글에서 호 자체를 편집하는 새 기능을 만든 것은 아니다.

## 반복에서 발견하고 고친 사항

1. 사용자 파일에는 라벨 30개 변경, 3번 그림의 약 0.9% 폭 조정, D의 앵커 이동이 있었다. 전체 재생성 대신 문단과 개체를 보존했다.
2. 첫 시안에서는 3번 본문과 그림이 다른 단으로 갈라져 4쪽이 됐다. 1·2번 뒤 간격을 줄인 두 번째 출력에서 3쪽 배치와 문항 묶음을 확인했다.
3. 2.2mm와 3mm 호를 실제 출력에서 비교하여 3mm를 선택했다. 크롭과 그림 비율은 유지했다.
4. 보기 앞 빈 문단은 삽입 조각에서 따라왔다. 실제로 빈 문단일 때만 제거하도록 수정하고, 새 문서를 만들어 확인했다.
5. 질문 문단에 앵커를 둔 D를 본문 수식으로 오인하던 검사를 고쳤다. 사용자 원본과 일치하는 점 이름·앵커만 인정한다. 새 라벨은 충돌 검사를 하고, 기존 라벨은 최종 시각 검토를 별도로 거친다.
6. 회귀검사가 표지 사각형을 움직이던 오류를 바로잡았다. 실제 수식 라벨을 옮긴 변조본은 `USER_LABEL_CHANGED`로 거부된다.
7. 독립 검토자가 2번의 대변을 이웃변으로 혼동한 초기 풀이를 원문 재검산으로 정정했다. 잘못된 검토를 그대로 반영하지 않았다.

## 검사 결과

- 최종 학생용·교사용 각 3쪽의 한글 열기, PDF 출력, 수식 실측·편집, 본문 흐름, 소유 한글 종료를 확인했다.
- 두 HWPX의 strict·XML·레이아웃 검사를 통과했다. 실제 PDF 6쪽을 작성자와 별도 검토자가 모두 확인했다.
- 13문항의 독립 풀이와 교사용 대조를 마쳤다. 두 전달 검사는 모두 `REVIEWED_WITH_INDEPENDENT_EVIDENCE`다.
- 새 보기 삽입의 질문 직후 배치, 선행 공백, 네 문장, 다음 문항 보존을 확인했다.
- 기본 3mm 호, 원래 호 보존, 사용자 좌표 보존, 임의 이동 거부 등 회귀 5항목을 통과했다.
- 스킬 형식과 JavaScript 문법 검사를 통과했다.

텍스트만 있는 `보기-회귀.hwpx`에는 수식이 없다. 이 진단 파일에 수식 편집 검사를 적용해 생긴 `EQUATION_EDIT_FAILED`와 `INLINE_FLOW_FAILED`는 검사 대상 불일치이며, 해당 기록을 PASS로 바꾸지 않았다. 보기의 구조 검사와 한글에서 출력한 PDF의 시각 확인으로 검증했다. 실제 학생용·교사용의 수식 편집 검사는 정상 통과했다.

## 스킬·파일 보존

실제 `pbj-exam-hwpx`의 `SKILL.md`, 수식·그림/양식·배치/한글 실행 참조 3개, `export_mathgraph.mjs`, `native_author.py`, `preserved_diagram_review.py`, `exam_tools.py`, `delivery_check.py`를 수정했다.

원본·사용자 수정본·이전 산출물은 덮어쓰거나 삭제하지 않았다. 날짜·교시는 미확정이므로 시행 전 확정해야 한다. 앱 소스와 운영 배포는 바꾸지 않았다. 이전 전송 승인 차단을 우회하지 않고 외부 업로드·푸시는 재시도하지 않는다. PDF는 저장소의 제외 규칙에 따라 로컬로 유지한다.
