# 제작 계획

## 적용 스킬

- `pbj-exam-hwpx`: 보관된 원안지 복제, 자동 번호·배점, 수식 개체, HWPX·PDF·검수 파일 제작
- `hancom-hwpautomation` 관련 공통 작성 도구: 한글의 `EquationCreate`와 원안지 스타일 사용
- `solo-ai-workbench`: 문항 원고·검산·실행 증거를 분리하고 검증 범위를 기록
- `routing-personal-playbooks`: 라우터를 확인했으나 현재 설치 상태가 `unavailable`이어서 일반 기준과 프로젝트 지침을 적용

## 산출물

1. `시험정보.json`: 시험 시기·학년·문항별 배점
2. `제작-시험지.py`: 학생용·교사용을 재생성하는 코드
3. 학생용 HWPX와 한글 출력 PDF
4. 교사용 정답·해설 HWPX와 한글 출력 PDF
5. 문항별 검산, 한글 실행 영수증, 학생용·교사용 검수 파일

## 완료 기준

- 학생용 13문항과 교사용 13문항의 번호·배점이 일치한다.
- 배점 합계는 `60점`이고, 3점 3문항·4점 3문항·5점 3문항·6점 4문항으로 배분한다.
- `exam_tools.py audit`와 HWPX strict 검사가 통과한다.
- 한글에서 직접 출력한 학생용·교사용 PDF의 모든 쪽을 확인한다.
- 문항별 계산과 선택지 판정이 교사용 해설과 일치한다.

## 남길 제한

- 실제 학교 시험 날짜·교시·출제 범위의 세부 평가계획은 제공되지 않았으므로 확인하지 않는다.
- 이 산출물은 특정 학교의 원문 기출을 인용한 것이 아니라 창작 문항이다.
