# 지필평가 HWPX 제작

사용자가 승인한 원안지를 **항상 복제하여** 시험지를 만든다. 원본 경로를 다시 묻지 않는다. 현재 요청에 다른 양식이나 파일 형식이 명시되면 그 요청을 우선한다.

## 정본과 변경 범위

- 원본: `assets/original-exam.hwp`, 한글에서 변환한 동일 양식: `assets/original-exam.hwpx`.
- 작성용 양식: `assets/blank-exam.hwpx`. 원본의 기존 문항·메모·정답 표시를 제거하고 변동 필드를 분리한 복사본이다.
- 원본 미리보기: `assets/reference-page-1.png`, `assets/reference-page-2.png`. 원본의 녹색 메모·노란 정답 표시는 최종 시험지에 넣지 않는다.
- 보기 상자 실측 자료: 사용자가 2026-09-13 제공한 `시험지 양식.hwp`를 변환한 `assets/layout-samples.hwpx`, 미리보기 `assets/reference-page-3-layout-samples.png`, 삽입 조각 `assets/statement-box.hwpx`. 보기 상자는 이 조각을 사용하며 선을 문자로 흉내 내지 않는다.
- 용지, 표지, 결재란, 학교명, 머리말·꼬리말, 표 구조·선·여백, 다단, 글꼴, 번호·선택지 스타일은 고정한다. 다른 서식으로 재작성하거나 직전 대화에서 임시 생성한 시험지를 정본으로 삼지 않는다.
- 연도·학기·시험 차수·명칭·날짜 등 시기별 표현을 바꾼다. 요청된 학년, 문항, 정답과 실제 문항 수·배점·쪽수도 해당 시험에 맞추되 **서식은 바꾸지 않는다**. 시험 날짜·교시·출제자 등 모르는 값을 지어내지 않는다.

## 매 제작 때 적용

1. [원본 양식과 배치](references/양식과-배치.md)를 읽는다. 실제 원본은 **세로 B4, 본문 2단**이다. 과거 문서의 ‘가로 B4’ 표현을 재사용하지 않는다.
2. [수식과 그림](references/수식과-그림.md)과 [rm/it 판단](references/rm-it-판단과-예시.md)을 읽는다. `hwpx`와 `hancom-hwpautomation`을 사용한다. 본문은 일반 텍스트 흐름 안에 한글의 `EquationCreate` 수식을 넣는다. 수식 크기를 임의 계산하거나 본문을 그림 라벨용 글상자로 만들지 않는다.
3. 출제 범위·유형·문항 수·배점·시험 시간을 정리하고 [문항별 검산과 독립 검토](references/문항별-검산과-독립검토.md)를 따른다. 보기마다 이유와 반례를 기록하고, 구한 값을 원래 조건에 대입한다. 아직 확인하지 않은 성취기준이나 실제 기출 출처를 꾸며 쓰지 않는다.
4. `scripts/exam_tools.py prepare --metadata 시험정보.json --output 시험지.hwpx`로 작성용 양식을 복제한다. 출력 파일은 원본·스킬 폴더 밖에 둔다. 준비 파일은 미완성이다.
5. [공통 작성 도구와 실행 절차](references/한글-실행과-전달검사.md)의 `native_author.NativeDocument`를 기본으로 사용한다. 선택형은 **선택형문항(번호자동부여)**, 논술형은 **논술형문항(번호자동부여)** 스타일로 넣는다. 번호를 문자열로 입력하지 않는다. 선택지는 원본의 1행·2행·3행·5행 스타일과 탭을 사용한다. ㄱ·ㄴ·ㄷ처럼 함께 판단할 문장은 `statement_box()`로 원본 보기 상자 안에 넣는다. 스타일 ID를 추측하지 말고 이름으로 찾는다.
6. 문항 본문·조건·그림·선택지를 한 덩어리로 배치한다. `question()`은 앞 문항의 마지막 선택지 뒤에 빈 본문 한 줄을 자동으로 확보한다. 명시적 `space()`, 단 나눔, 쪽 나눔 뒤에는 같은 여백을 중복하지 않는다. 단별 배치표에 실제 문항을 배정한다. 고정 문항 수가 있는 것으로 오해하지 않는다. 그림 문항은 왼쪽 단 3~4개를 우선 검토하되 길이와 풀이 공간 때문에 무리하게 압축하지 않는다.
7. **그림은 문제 이해에 도움이 된다고 판단되면 MathGraph로 기본적으로** 만든다. 관련 그림 유형만 `mathgraph-drawing` 스킬을 읽고 앱의 내보내기/한글 입력 경로로 넣는다. 다만 그림 자체가 선택지의 정답을 직접 드러내거나, 문항의 정보를 그대로 반복해 가독성을 해치는 경우에는 만들지 않는다. 시험 도형은 기본 `lineWidth=3`, HWP 폭 68.2mm이고, 점 이름은 한글 수식 13pt다. 문제에 주어진 각은 각도 호와 값, 특정 선분의 길이·대수식은 해당 선분 가까운 치수 라벨로 함께 표시한다. 도형은 글자처럼 취급하여 별도 가운데 정렬 문단에 두고 라벨이 같은 문단 앵커를 따라 이동하게 한다.
8. [출제 및 납품 검사](references/출제와-검수.md)와 [실패 원인·재발 방지](references/실패-원인과-재발방지.md)를 적용한다. 최종 HWPX를 한글에서 직접 PDF로 출력하고 두 파일의 해시·수식 실측·편집·전체 쪽 검수 기록을 연결한다. `audit`의 구조 검사는 실제 한글 열림·수식 편집·전체 쪽 렌더 검사를 대신하지 않는다.
9. 별도 검토자가 학생용만 먼저 풀어 기록한 뒤 교사용과 대조한다. [schema 2 전달 검사](references/한글-실행과-전달검사.md)로 실제 종료·그림 위치·보기별 판정·독립 검토를 연결한다. 미해결 결함을 없앤 뒤 학생용 HWPX와 분리된 교사용 정답·해설 HWPX를 전달한다. 인쇄용 PDF도 같이 내보내 화면을 확인한다. 검증 미완료 파일을 ‘바로 시행 가능한 시험지’로 표현하지 않는다.

## 도구

그림의 점 이름은 13pt, 길이·각 조건은 11pt의 인쇄 크기로 고정한다. 한글에서 실측한 수식 영역으로 선·점·다른 라벨과의 충돌을 검사하고 `diagram_receipts`를 보관한다. 길이 표시 점선은 실선과 같은 굵기로, 휨이 충분히 보이게 내보낸다. 실제 HWPX와 PDF의 겹침·조건 누락 검사까지 통과해야 그림 검수를 마친다. 세부 기준은 [수식과 그림](references/수식과-그림.md)을 따른다.

```text
python scripts/exam_tools.py inspect 문서.hwpx
python scripts/exam_tools.py prepare --metadata 시험정보.json --output 새시험지.hwpx
python scripts/exam_tools.py audit 시험지.hwpx --mc 4 --essay 1 --points 20
```

```python
doc.question([('text','항상 옳은 것만 고르시오.')],2)
doc.statement_box([
    [('text','첫째 문장')],
    [('text','둘째 문장')],
    [('text','셋째 문장')],
])
doc.choices([[('text','ㄱ')],[('text','ㄴ')],[('text','ㄱ, ㄴ')],[('text','ㄴ, ㄷ')],[('text','ㄱ, ㄴ, ㄷ')]],rows=(3,2))
```

`prepare`의 입력 형식과 한글 작성 방법은 [작성 도구 사용법](references/작성-도구.md)에 있다. 수식 변환은 `scripts/equations.py`의 `to_hwp(latex)`를 사용한다. 지원하지 않는 명령은 실패로 처리하며, 변환이 필요한 한 문항 때문에 새 수식 체계를 만들지 않는다.

새 시험지 제작은 스킬·전역 지침·원본을 다시 수정하는 요청이 아니다. 이 스킬의 생성·수정 권한을 파일 외부 전송·배포 권한으로 확대하지 않는다.
