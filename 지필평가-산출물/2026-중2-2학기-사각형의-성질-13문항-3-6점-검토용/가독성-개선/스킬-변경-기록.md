# 시험지 도형 가독성 수정 기록

## 원인과 수정

- 화면용 글꼴을 인쇄 크기로 환산하면서 조건 글자가 5pt까지 작아졌다. 점 이름은 화면 배치 후 13pt로 확대했지만 배치를 다시 계산하지 않았다. 점 이름은 13pt, 조건은 11pt로 먼저 확정하고 한글 수식 엔진의 실측 폭·높이로 배치하도록 바꿨다.
- 도형의 선·점·다른 글자를 함께 검사하지 않았다. 실제 도형 PNG와 한글 수식 영역 사이에 기본 0.9mm를 확보하며, 국소 이동으로 해결되지 않으면 그림 구도를 바꾸도록 했다. 최종 저장 좌표도 별도로 다시 검사한다.
- 글상자가 외부 선과 겹치지 않아도 내부 문단 여백 때문에 마지막 숫자가 잘렸다. 문단 여백·들여쓰기를 초기화하고 글상자 폭에는 실측 수식보다 4mm, 높이에는 2mm 여유를 뒀다. 최종 3x−2 라벨의 마지막 2를 PDF 300dpi 확대에서 확인했다.
- 구형 MathGraph의 치수선은 객체 설정과 달리 내부에서 1px로 그려졌다. 시험지 내보내기 경로에서 실선과 같은 굵기를 적용했다. 길이 호의 휨을 키우고 라벨 부분은 실제 곡선을 끊어 확보한다. 흰색 상자로 도형을 덮지 않는다.
- ±180도 경계를 지나는 각 라벨이 빠지는 경우를 보완했다. 조건 문자열이 실제 내보내기와 최종 HWPX에 있는지도 검사한다.
- 과거 도형 검수의 expected 값 일부가 문제를 풀어 구한 값이 아니라 잘못 그린 현재 좌표에서 나온 값이었다. 이를 검증 근거로 재사용하지 않고 원래 조건을 풀어 도형 좌표와 검산값을 다시 작성했다. 선택형8번의 불가능한 변·대각선 조건도 6·8·10 관계를 만족하도록 고쳤다.

## 사용 시 유의점과 복구

수정본은 창작 문항이며 실제 학교 기출을 복제한 것이 아니다. 날짜·교시는 비워 둔 검토용이다. 실제 시행 전 학교 교육과정·난도와 채점 운영 기준은 교사가 최종 확정한다.

기존 시험지는 덮어쓰거나 삭제하지 않았다. 새 시험지가 있는 `가독성-개선` 폴더와 구분하여 이전 파일로 돌아갈 수 있다. 이 폴더에는 원인 확인에 사용한 중간본도 있으므로 실제 검토에는 학생용 `완성.hwpx/pdf`, 교사용 `채점보완.hwpx/pdf`를 사용한다.

독립 검토 첫 대조에서 정답 13개와 전체 도형 가독성은 확인됐지만 논술형2·4번의 부분 정답 채점 기준이 모호해 FAIL이었다. 교사용만 새 파일로 생성하여 미지수와 네 각 전체의 정답 여부, 각 일부 정답의 가점 제외, 나머지0점, 오류 전파 인정의 적용 범위를 명시했다. 동치 풀이 인정 공통 규칙도 추가했다. 학생용은 변경하지 않았다.

이전 원격 전송이 승인 검토에서 차단되어 이번에는 GitHub 푸시를 재시도하지 않는다. 시험지와 검수 자료를 외부 서비스에 올리거나 Vercel에 배포하지 않는다.
