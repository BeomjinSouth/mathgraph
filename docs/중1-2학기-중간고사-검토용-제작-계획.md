# 중1 2학기 중간고사 검토용 시험지 제작 계획

## 목표

`blank-exam.hwpx`를 복제하여 중학교 1학년 2학기 수학 검토용 시험지의 학생용·교사용 HWPX와, 각 HWPX를 한글에서 직접 저장한 PDF를 만든다. 재실행 코드, MathGraph 도형 원본·내보내기, 수학·배치·전달 검사 기록까지 같은 새 출력 폴더에 보관한다.

## 확인한 근거와 범위

- 교과서: `중_수학1(김화경)_교과서.pdf`의 차례를 직접 확인했다.
- 출제 범위: 점·선·면, 각, 점·직선·평면의 위치 관계, 평행선의 성질, 삼각형의 작도·합동, 다각형, 다각형의 내각과 외각, 원과 부채꼴, 다면체와 회전체, 기둥·뿔·구의 겉넓이와 부피, 대푯값, 줄기와 잎 그림·도수분포표, 히스토그램이다.
- `히스토그램까지`는 교과서의 다음 절인 도수분포다각형·상대도수는 포함하지 않는 것으로 해석한다. 실제 시행 범위가 다르면 문항만 다시 조정한다.
- 실제 학교 시험 표지에서 확인한 배점 근거는 선택형 23문항, 총 100점이며 `3점×4`, `4점×9`, `5점×8`, `6점×2`이다. 따라서 이번 검토용도 같은 구성으로 만든다.

## 미확정 정보 처리

- 실제 시험일·교시·성취기준 번호·학교 평가계획은 확인하지 못했으므로 표지의 해당 칸을 비운 검토용으로 만든다.
- 2026은 현재 제작 연도와 교과서 보관 경로에서 확인되지만, 시험 시행일을 뜻하지 않는다.
- 시험 쪽수는 생성 뒤 실제 한글 PDF의 쪽수를 기준으로 확정한다. 첫 실제 한글 PDF가 세로 B4 2단 4쪽으로 확인되어, 최종 표지는 4쪽으로 맞춘다. 글자 크기·쪽 여백을 줄여 3쪽으로 압축하지 않는다.

## 문항·배치 기준

- 모든 문항은 선택형 5지선다이며, 원본의 자동 문항 번호와 선택지 1·2·3·5행 스타일을 쓴다.
- 문항 1~4는 3점, 5~13은 4점, 14~21은 5점, 22~23은 6점으로 한다.
- 수학 숫자·문자·기호·단위는 모두 인라인 한글 수식 개체로 넣는다. 점·선분·각 이름과 단위는 정체, 변수는 기울임으로 검수한다.
- 그림이 실제로 필요한 위치 관계·평행선·입체도형 문항에만 MathGraph 도형을 쓰며, 이미지 안의 점 이름은 편집 가능한 한글 수식 라벨로 분리한다.
- 각 문항의 본문·그림·마지막 보기 ⑤가 같은 쪽·단에 있게 실제 PDF 문자 위치를 확인한다.

## 완료 기준

1. 학생용과 교사용 최종 HWPX의 strict 구조 검사와 원안지 구조 검사를 통과한다.
2. 각 최종 HWPX를 한글에서 열어 PDF로 저장하고, 수식 치수·편집성·본문 흐름·소유 문서/창/프로세스 종료를 확인한다.
3. 모든 PDF 쪽과 모든 문항을 직접 검토하고, 보기별 참·거짓·정답 유일성·문항 간 답 노출·범위·배점을 기록한다.
4. 학생용만 먼저 푼 별도 검토 결과를 교사용 해설과 대조하고, 해시가 연결된 schema 2 전달 검사를 통과한다.

## 비대상

- MathGraph 웹앱 코드·운영 배포·Vercel 설정은 변경하지 않는다.

## 완료 기록

- 최종 전달본은 `outputs/2026-중1-2학기-중간고사-검토용/전달용-최종본-수정5`에 보관한다. 이전 생성 후보와 중단본은 삭제하지 않았다.
- 학생용은 선택형 23문항 100점(3점 4문항, 4점 9문항, 5점 8문항, 6점 2문항)이며, 학생용·교사용 HWPX와 한글에서 직접 저장한 PDF가 각각 4쪽이다.
- 독립 검토에서 발견한 2번 복수정답을 `DA`와 `BD`가 시작점이 다른 보기로 고쳤다. 22번은 도수분포표를 히스토그램으로 나타낼 때 가장 높은 직사각형의 계급을 묻는 문장으로 고쳐 ③이 유일한 정답이 되게 했다.
- 교사용은 1~6, 7~13, 14~20, 21~23번으로 쪽을 나누어 문항 제목과 해설이 서로 다른 쪽에 분리되지 않게 했다.
- 표지 배점 문구는 원안지 메타데이터와 같게 유지했고, 한글 저장 뒤 바뀐 표지 배점 표의 바깥 높이는 원안지 값으로 복원한 뒤 실제 PDF에서 두 줄 모두 테두리 안에 있음을 확인했다.
- `fill_hwpx.py check --strict`, 원안지 표·문항·배점·그림 구조 검사, 한글 수식 편집성·흐름·종료 검증, 전체 PDF 렌더 검토, 문항별 검산, 독립 검토, 학생용·교사용 전달 검사를 모두 통과했다.
