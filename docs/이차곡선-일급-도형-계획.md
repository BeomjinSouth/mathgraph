# 이차곡선 일급 도형 구현 계획

## 목표

MathGraph가 특정 시험 문제의 선분 근사에 의존하지 않고 타원, 쌍곡선, 포물선을 정식 객체로 생성·렌더링·선택·이동·저장·복원·SVG 내보내기할 수 있게 한다. AI 구조화 출력과 장면 그래프에서도 같은 객체 계약을 사용한다.

## 객체 계약

- `ellipse`: 중심 `x`, `y`, 양의 반지름 `radiusX`, `radiusY`, 선택적 회전각 `rotation`(라디안)
- `hyperbola`: 중심 `x`, `y`, 양의 매개변수 `a`, `b`, `orientation`(`horizontal` 또는 `vertical`), 선택적 `rotation`(라디안)
- `parabola`: 꼭짓점 `x`, `y`, 양의 초점거리 `p`, `orientation`(`right`, `left`, `up`, `down`), 선택적 `rotation`(라디안)

회전은 각 도형의 표준 위치 좌표에 적용한다. 포물선은 `right`일 때 `v²=4pu`, 쌍곡선은 `horizontal`일 때 `u²/a²-v²/b²=1`을 기준으로 한다.

## 영향 범위

1. 기하 객체 타입, 렌더링, 선택 판정, 드래그, 직렬화
2. 객체 관리자 생성·복원
3. AI 엄격 스키마, 로컬 스키마 검증, 패치 생성·수정
4. 고수준 장면 그래프 컴파일
5. SVG 내보내기
6. AI 참조 매뉴얼과 프로젝트 진행 기록

## 제외 범위

- 이차곡선과 다른 객체의 자동 교점 계산
- 이차곡선 위 종속점 도구와 접선 자동 구성
- 도구막대에 별도의 수동 이차곡선 그리기 도구 추가
- 문제의 미지수를 자동으로 풀어서 도형 매개변수를 결정하는 기능

점과 보조선은 기존 자유점·선·텍스트 객체로 함께 구성할 수 있다. 이번 구현은 곡선 자체를 선분 묶음이 아닌 편집 가능한 객체로 만드는 데 집중한다.

## 완료 기준

- 세 객체가 유효한 매개변수로 생성되고 잘못된 크기·방향은 거부된다.
- 선택, 이동, 저장·복원 후에도 수학적 매개변수가 보존된다.
- AI `operations[]`와 장면 그래프가 세 객체를 생성할 수 있다.
- 캔버스와 SVG에서 세 곡선이 매끄럽게 출력된다.
- 기존 전체 테스트, 정적 빌드, `git diff --check`가 통과한다.
- 브라우저에서 타원 예시와 쌍곡선·포물선 예시를 실제로 렌더링하고 콘솔 오류가 없는지 확인한다.

## 검증 흐름

브라우저 대상 흐름은 `앱 열기 → AI 작업 JSON으로 이차곡선 생성 → 캔버스에 곡선과 라벨 표시 → 객체 선택 또는 이동 → 상태 보존 확인`이다.

배포는 필수 운영 환경 변수가 확인되고 Vercel 인증이 복구된 경우에만 수행한다. 이 조건이 충족되지 않으면 로컬·브랜치 검증까지만 완료하고 차단 사유를 진행 기록에 남긴다.
