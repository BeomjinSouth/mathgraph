# 앱 AI 그림 확인 기능의 운영 반영

2026-10-01 사용자가 운영 반영을 요청했다. 기준은 원격 main 39f6c81과 동일한 운영 READY 배포다. Production Branch는 main을 유지한다.

## 범위와 성공 기준

치수·곡선 지시 화살표와 앱의 실제 그림 확인·수정 흐름을 최신 main에 통합한다. 기존 통계·집합·전개도, 문제 작성, 인쇄/내보내기와 수동 치수 지원을 보존한다. 원본 작업 폴더의 사용자 파일·미커밋 수정은 운영 병합에 포함하지 않는다.

기존 코드 전용 worktree에서 최신 origin/main으로 통합 브랜치를 만들고 해당 기능의 네 커밋만 가져온다. 충돌에서는 main의 출력용 길이 호·실제 모서리 선택·다중 각도 호·히스토리·사진 중단/오류 처리와 신규 기능을 함께 유지한다.

전체 테스트·정적 빌드, 앱의 실제 그림 확인 회귀 흐름, 기존 교과 기능의 브라우저 검사를 통과한 뒤 main에 병합하고 원격 main을 반영한다. 자동 운영 배포가 READY인지, 소스가 원격 main인지, 운영 별칭이 새 배포인지, 실제 운영 앱과 주요 흐름이 작동하는지 확인한다. API 키·환경 변수 값은 읽거나 출력하지 않는다.

## 진행

- 통합 기준·운영본 확인 완료. 적용 대상 커밋을 가져왔고 충돌에서 기존 기능을 보존했다. 통합 검사에서 치수 글자 클릭 영역을 실제 숫자 중심에 맞추고, 기존 점 모양 선과 인쇄용 호·글꼴·여백을 유지했다. 자동 라벨 배치도 실제 렌더된 호를 사용한다. 다중 호·직각 같음 표시가 원호를 유지하는 회귀 검사를 추가했다.
- 전체 검사·정적 빌드, 시험 그림 100종·복합 45종과 오류 탐지, 교과 기능 43종·속성 수정·잘못된 입력·모바일, 앱 그림 검토 12개 흐름을 통과했다. 미처리 브라우저 오류는 0건이다. 근거는 `output/production-review`와 `output/ai-drawing-review`에 있다. 외부 모델 응답은 고정했고 실제 임의 문항 정확도로 해석하지 않는다.
- Production 환경의 OPENAI_API_KEY·MATHGRAPH_LOGIN_SECRET·MATHGRAPH_OWNER_PASSWORD 이름과 암호화 상태를 재확인했다. 실제 값은 읽지 않았다. GitHub/Vercel 연결과 Production Branch main을 확인했다.
- 문제가 발견되면 운영 반영 전에 수정한다. 배포 실패 시 기존 검증 main의 운영본을 기준으로 복구하며, 작업 브랜치를 운영 주소에 직접 연결하지 않는다.
