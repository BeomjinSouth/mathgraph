# 교사용 사이트 준비도 점검 — 2026-07-10

## 결론

MathGraph는 데스크톱에서 교사가 수학 도형을 직접 만들고, AI로 문제 그림을 생성하며, PNG/SVG로 내보내는 핵심 흐름까지 구현된 **실사용 베타 단계**다. 다만 로컬 보안 강화본과 실제 배포본이 서로 다르고, 모바일 편집 화면이 사실상 동작하지 않으며, 운영 보안·장시간 AI 요청·복합 도형 복사 관련 위험이 남아 있어 현재 상태를 그대로 정식 공개하기에는 이르다.

> 이 문서의 본문은 2026-07-10 당시의 점검 스냅샷이다. 아래 후속 상태가 현재 로컬 릴리스 후보를 설명하며, 운영 배포가 끝나기 전까지 원래 결론의 “정식 공개 보류” 판단은 유지한다.

## 2026-07-13 후속 상태

- 로컬 릴리스 후보에서 모바일 390×844 캔버스 0px 문제, 터치/펜 입력, 명령 팔레트 XSS, 로그인/프록시 방어, 복합 도형 복사 참조, 직접 편집 실행 취소, 저장/불러오기/로그아웃 진입점, 무동작 빌드 게이트를 모두 수정했다.
- 최종 보안 검토에서 발견된 고유 이름 회전 로그인 우회도 주소 전체+주소/계정 이중 제한, 8 KB 본문 및 필드 길이 제한, 해시 키, 로그인/프록시 분리 저장소, 2048개 상한과 포화 시 신규 키 차단으로 닫았다.
- 자동 테스트와 Vercel 빌드 게이트는 각각 295/295, 네 화면 크기 브라우저 QA와 데스크톱 입력 회귀는 콘솔 오류 0건으로 통과했다.
- 운영 배포는 아직 하지 않았다. 마지막 성공한 Vercel 환경 이름 확인에서 `MATHGRAPH_OWNER_PASSWORD`가 없었고 현재 로컬 Vercel 인증도 만료되어, 소유자가 두 조건을 해결한 뒤 배포·운영 스모크를 실행해야 한다.
- 시각 자료:
  - 현재 데스크톱: `docs/design-references/teacher-workflow/current-workspace.png`
  - 현재 AI 패널: `docs/design-references/teacher-workflow/current-ai-assistant.png`
  - 현재 내보내기: `docs/design-references/teacher-workflow/current-export.png`
  - 16:9 모바일 목표: `docs/design-references/teacher-workflow/mobile-responsive-target-2026-07-10.png`
- 모바일 목표 이미지는 구현 방향의 시각 기준이다. 목표의 `MathGraph`·`AI 도우미` 표기와 현재 화면의 `그래프A`·`AI 어시스턴트` 표기가 달라 픽셀 단위 동일성을 주장하지는 않는다.

## 확인된 구현 범위

- 점, 선, 원, 다각형, 채우기, 작도, 측정, 함수, 각기둥·각뿔 등 교과서형 도형 편집
- 스냅, 좌표 편집, 화면 이동, 선택, 드래그 선택, 복사·붙여넣기, 실행 취소·다시 실행, 명령 팔레트
- 흑백 교과서 스타일, 수식·분수·음수 표기, 반직선·축 화살표
- 전체/잘라낸 PNG 및 SVG 내보내기
- 자연어·문제 문장·참고 이미지 입력을 통한 편집 가능한 그림 생성
- 소유자 프록시 로그인과 게스트 개인 API 키/로컬 대체 흐름
- 운영 주소 `https://mathgraph-five.vercel.app` 공개 및 응답 확인

## 부분 완료 또는 미완료

- 전체 문제 문장 실연 3건 중 1건만 제한 시간 안에 완료되었고, 2건은 150~180초 구간에서 대기 시간 초과가 발생했다.
- 이미지/PDF 재현용 장면 그래프 파이프라인은 존재하지만 모든 실시간 입력 경로가 이 파이프라인으로 통일되지는 않았다.
- 히스토그램·상자그림·산점도 같은 통계 그래프, 원기둥·원뿔·구·전개도, 독립 텍스트, 완전한 PDF 가져오기/내보내기는 아직 없다.
- 저장/불러오기는 명령 팔레트에 숨겨져 있고, 로그아웃·사용 모드 전환은 화면에서 찾기 어렵다.
- 일부 계획 문서와 README가 현재 구현 및 배포 상태를 따라가지 못한다.

## 우선순위별 개선 항목

### P0 — 모바일 편집 화면 복구

- 390×844 화면에서 왼쪽 도구 패널이 320px를 차지해 중앙 캔버스 폭이 0px가 되고, 오른쪽 속성 패널은 화면 밖으로 밀려난다.
- 본문이 `overflow: hidden`이라 밀려난 영역으로 이동할 수도 없다.
- 편집 입력이 마우스 이벤트 중심이라 터치·펜 입력 지원이 부족하다.
- 모바일에서는 도구/속성 패널을 서랍 또는 하단 시트로 전환하고, 캔버스 최소 폭과 포인터 이벤트를 보장해야 한다.

### P1 — 로컬 보안 개선본을 검증 후 배포

- 현재 로컬에는 이름+비밀번호 로그인, 서명 비밀키 필수화, 프록시 모델 제한·요청 크기 제한·속도 제한 등이 추가되어 있으나 커밋·배포되지 않았다.
- 실제 운영 화면은 여전히 이름만 받는 이전 로그인 흐름이다.
- 새 코드 배포 전에 Vercel Production에 `MATHGRAPH_OWNER_PASSWORD`가 설정되었는지 확인해야 한다. 없으면 소유자 로그인이 503으로 비활성화된다.
- 로그인 엔드포인트 자체에도 계정/주소 기준 시도 제한을 추가해야 한다. 현재 프록시의 토큰별 제한만으로는 반복 로그인 시도를 막지 못한다.

### P1 — DOM XSS 잔여 지점 수정

- 명령 팔레트 검색어가 `js/ui/CommandPalette.js`에서 이스케이프 없이 `innerHTML`에 들어간다.
- 게스트 API 키와 소유자 토큰을 같은 출처의 스크립트가 읽을 수 있으므로, 이 지점은 단순 표시 오류보다 우선순위가 높다.
- 공용 HTML 이스케이프 함수를 적용하고 정규식 특수문자도 별도로 이스케이프해야 한다.

### P2 — 서버 요청 방어 보완

- 이미 파싱된 객체 형태의 요청 본문은 `lib/ownerAuth.js`에서 크기 계산 없이 통과해 최대 본문 크기 제한을 우회할 수 있다.
- 프록시는 모델 외 Responses 요청의 대부분을 그대로 전달하므로, 비용이 큰 기능·출력량·도구 사용에 대한 정책 제한이 필요하다.
- AI 요청에 애플리케이션 수준 취소·시간 제한이 없어 실제 150~180초 대기 사례와 연결된다.

### P2 — 편집 무결성 및 품질 관문 보완

- 복합 도형 복사 시 `vertexIds`, `topVertexIds`, `circle1Id`, `circle2Id` 등의 참조를 새 객체 ID로 모두 바꾸지 않아 복사본이 원본을 참조할 수 있다.
- `vercel-build`는 현재 메시지만 출력하는 무동작 스크립트라 배포 전 품질 관문 역할을 하지 못한다.
- 일부 직접 속성 변경과 대수 목록/명령 팔레트 작업의 실행 취소 일관성을 실제 브라우저에서 추가 확인해야 한다.

### P2 — 모델 구성·문서 최신화

- 클라이언트와 서버의 모델 목록이 GPT-5.4/5.5 계열로 중복 관리된다. 2026-07-10 공식 모델 문서는 GPT-5.5를 기본 권장하고 GPT-5.6을 제한된 파트너 미리보기로 안내하므로, 이번 릴리스에서는 기존 모델을 유지하되 공유 구성 또는 환경 변수 한 곳에서 관리하는 편이 안전하다.
- README, 구현 계획, 진행 체크리스트를 실제 인증·배포·기능 상태에 맞게 정리해야 한다.

### P3 — 접근성과 정보 구조 개선

- 캔버스 조작은 키보드/스크린리더로 대체하기 어렵고, 객체 행은 클릭 가능한 `div` 중심이다.
- 대화상자에 `dialog` 의미, 포커스 고정·복원, 배경 비활성화가 부족하다.
- 알림과 AI 응답은 라이브 영역으로 안내되지 않고, 여러 버튼의 터치 목표가 44px보다 작다.
- 우측 AI 패널이 편집 영역 위를 덮으므로 데스크톱에서도 캔버스 가시 영역을 줄이거나 크기 조절 가능한 패널로 바꾸는 것이 좋다.

## 증거 한계

- 운영 소유자 비밀번호와 비용이 발생하는 실시간 AI 호출은 이번 점검에서 실행하지 않았다.
- Vercel CLI 인증이 없어 현재 운영 배포 ID를 새로 확인하지 못했으며, 공개 주소의 HTTP 응답과 브라우저 동작으로 상태를 확인했다.
- 브라우저 화면 캡처는 모바일 작업공간만 저장되었고, 데스크톱/AI 확장 상태 캡처는 도구 시간 초과로 남기지 못했다.
- 이번 작업은 점검과 기록만 수행했으며 제품 코드는 변경하거나 배포하지 않았다.

## 권장 실행 순서

1. 기존 로컬 보안 변경을 작은 단위로 검토하고 잔여 XSS·로그인 제한·본문 크기 우회를 함께 수정한다.
2. Production 환경 변수 확인 후 테스트·브라우저 검증을 거쳐 보안 개선본을 배포한다.
3. 모바일 패널 구조와 포인터 입력을 별도 기능 작업으로 설계·구현한다.
4. 복합 도형 복사 참조와 실행 취소 일관성에 회귀 테스트를 추가한다.
5. 실제 빌드 품질 관문, AI 취소/시간 제한, 모델 구성, 문서를 정리한다.
