# 중·고등 수학 그림 지원 확대

작성일: 2026-09-28. 기준 커밋: 7b23d15.

## 목표와 범위

중·고등 수학의 그림 요청을 기능군별로 점검하고, 명시적으로 지원하지 않던 기능을 실제 편집 가능한 객체로 구현한다. 임의의 모든 문제를 완벽히 이해한다고 보장하지 않으며, 요청한 조건을 누락하거나 임의의 자료로 바꾼 결과를 성공으로 반환하지 않는다.

1. 기존 평면기하·원·수직선·함수·이차곡선·벡터·입체의 회귀 검증을 유지한다.
2. 막대그래프·원그래프·히스토그램·도수분포다각형·상자그림·점도표·산점도를 자료를 보존하는 전용 객체로 추가한다.
3. 고리 부채꼴의 실제 구멍과 곡선 경계를 구현한다.
4. 정육면체·직육면체·원기둥·원뿔 및 정각기둥·정각뿔의 전개도를 치수 기반으로 추가한다.
5. 고등학교 확률분포·집합·경우의 수·함수 요청의 빈틈을 조사하고 재현되는 오류와 필요한 생성 경로를 보완한다.

## 사용자 흐름과 제약

기존 AI 입력 → 요청 해석 → 조건/자료 검사 → 편집 가능한 그림 → 속성 수정 → 저장/내보내기를 유지한다. 새로운 화면 개편은 하지 않는다. 자료가 빠지거나 불가능한 치수이면 구체적인 입력 오류를 반환한다. 흑백을 기본으로 하고 기존 교사 라벨 위치와 사용자 파일을 보존한다. API 모델·인증·요금 설정은 변경하지 않는다.

## 완료 기준

- 새 객체가 생성·수정·삭제, 이동, 실행 취소/재실행, JSON 저장 왕복, Canvas와 SVG 출력에서 동일한 의미를 유지한다.
- AI 명령 스키마·장면 변환·지원 안내·기능 매뉴얼에 실제 구현 범위를 반영한다.
- 정상 자료와 잘못된 자료, 한국어 표현 변형, 복합 조건, 기존 기능을 포함한 반복 가능한 검증 모음을 만든다.
- 실제 브라우저 화면을 캡처하고 자료·치수·라벨·음영을 검사한다. 합성 검증과 실제 외부 AI 호출을 구분한다.
- 기존 필수 테스트와 정적 빌드를 통과하고 변경분만 커밋·작업 브랜치 푸시한다. 운영 배포는 main 반영 승인 없이 변경하지 않는다.

## 상태

구현과 로컬 검증을 마쳤다. 통계 8종·확률질량함수·정규분포, 전개도 6종, 고리 부채꼴, 2~3집합 벤 다이어그램을 전용 객체에 연결했다. 신규 한국어 요청 43건과 기존 복합 도형 45종을 실제 앱에서 검증했다. 범위 밖의 요청과 외부 AI 대량 평가 미실시 범위는 `중고등-그림지원-범위와검증.md`에 구분했다. 원격 반영 상태는 진행 기록과 완료 보고를 따른다.
