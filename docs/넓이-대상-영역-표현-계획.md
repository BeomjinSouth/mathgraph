# 넓이 대상 영역 표현 계획

## 목표

수학 문제 그림에서 넓이를 실제로 구하거나 최대화·최소화하는 닫힌 도형은 옅게 채우고, 넓이가 단지 조건으로 주어진 도형은 모범 답안처럼 외곽선만 그린다.

## 적용 범위

- 전체 문제문을 입력한 `problem_diagram` 흐름
- 문제 사진을 재구성하는 이미지 흐름
- AI가 만든 `polygon`의 채움 보정
- 꼭짓점 이름이 분명한 삼각형·사각형에서 빠진 목표 영역 생성

## 판단 규칙

1. “사각형 PQOR의 넓이의 최댓값”처럼 질문에서 넓이 자체를 구하거나 최대화·최소화하면 해당 도형을 `polygon`으로 만들고 `fillOpacity`를 `0.18` 이상으로 둔다.
2. “사각형 ADCB의 넓이가 25이다”, “삼각형 ABP의 넓이가 삼각형 AOB의 넓이의 5배이다”, “삼각형 FF'Q의 넓이가 4√5이다”처럼 넓이가 조건일 뿐 질문 대상이 다른 값이면 자동으로 채우지 않는다.
3. 사진에 모범 그림이 있으면 인쇄된 채움 여부와 선분을 우선하여 보존한다.
4. 채움은 검은색 또는 회색의 낮은 불투명도로 표현하고, 점 이름과 선이 읽히도록 한다.

## 모범 답안 대조 기준

- 17번: 사각형 `P-Q-O-R`을 옅게 채우고 `P-Q-O-R-P` 경계를 유지한다.
- 20번: 삼각형 `AOB`, 직선 `PC`, 내분점 `P`를 그리되 영역을 채우지 않는다.
- 26번: 평행한 두 직선과 사각형 `A-D-C-B`를 외곽선으로만 그린다.
- 타원: 타원, 초점 `F`, `F'`, 현 `PQ`, 선분 `F'Q`를 보존하고 영역을 채우지 않는다.

## 완료 기준과 검증

- 넓이 질문과 넓이 조건을 구분하는 단위 테스트가 통과한다.
- 17번에서 빠진 채움 영역이 자동으로 생성되거나 기존 다각형의 채움이 보정된다.
- 20번·26번·타원 반례에는 자동 채움이 생기지 않는다.
- 네 그림을 실제 브라우저에서 다시 렌더링하여 모범 답안과 대조한다.
- 전체 테스트, 정적 빌드, `git diff --check`를 통과한다.

## 작업 결과

- 넓이 자체를 구하거나 최대화·최소화하는 이름 붙은 다각형만 옅게 채우도록 구현했다.
- 넓이가 주어진 조건이고 다른 값을 묻는 문제는 채우지 않는 반례 검증을 추가했다.
- 17번·20번·26번·타원 그림을 브라우저에서 모범 답안과 대조했고, 타원에는 빠졌던 선분 F′Q를 추가했다.
- 전체 345개 테스트와 정적 빌드가 통과했다. 실제 OpenAI 이미지 업로드는 API 키가 없는 게스트 환경이라 실행하지 못했다.
