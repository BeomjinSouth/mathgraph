# 앱 AI의 그림 확인과 수정

## 요구사항과 범위

사용자는 Codex에서 요청하는 기존 제작 경로를 유지하면서 앱의 생성 정확도를 그 흐름에 가깝게 바꾸도록 요청했다. 앱의 자연어·이미지 요청에만 `생성 → 임시 렌더 → 원래 조건과 그림 확인 → 수정 → 재확인 → 반영`을 연결한다. 직접 JSON 입력과 Codex용 스킬·기존 제작 스크립트는 변경하지 않는다.

## 구현 기준

- 기존 조건 검사와 자동 배치를 재사용한다. 임시 객체와 화면에서 검사하고 최종 결과만 기존 한 번의 실행 취소 단위로 적용한다.
- 원래 요청, 필요한 기능 설명, 기존 객체, 생성 명령, 실제 렌더 이미지와 원본 이미지(있으면)를 함께 검토한다. 각도 숫자·호의 연결, 길이 숫자와 점선 간격, ABC 위치, 곡선 지시 화살표의 교차, 누락 조건을 구체적으로 확인한다. 문제를 풀어 정답을 추가하지 않는다.
- OpenAI·Gemini의 현재 선택된 제공자를 유지한다. 추가 검토는 최대 2회이고 수정은 최대 1회다. 검토에도 API 사용량과 대기 시간이 추가된다. 새 의존성·서버·계정·모델 변경은 없다.
- 수정 응답은 엄격한 형식과 기존 의미 검사를 다시 통과해야 한다. 기존 객체에 대한 수정 대상과 필드를 넓히지 않으며 잠긴 객체를 보호한다.
- 요청 진행 중 다른 AI 요청은 중복 실행하지 않는다. 중단·실패·검토 중 수동 편집은 기존 화면에 늦은 결과를 덮어쓰지 않는다.
- 모델이 확인하지 못했거나 수정 후에도 문제가 남으면 완료로 표시하지 않는다. 검토 결과와 검토 전 초안을 구분하고, 사용자가 초안을 직접 반영할 수 있게 한다. API가 없는 로컬 생성은 기존 작동을 유지하면서 이미지 검토 미실시를 명시한다.

## 화면 기준

기존 채팅과 상태 영역 안에서 `그림 생성 중`, `그림 확인 중`, `표시 수정 후 다시 확인 중`을 알린다. 중단과 필요할 때만 초안 반영 버튼을 둔다. 별도 화면 개편은 하지 않는다. Design.md/Soul.md는 없으며 기존 화면·사용자 요청·pbj-ui-copy를 기준으로 한다. 모바일 줄바꿈, 키보드 조작, 상태 전달을 확인한다.

## 적용 지침과 검증

mathgraph-drawing, openai-vibecoding-context, openai-docs, pbj-ui-copy를 적용한다. 개인 플레이북은 unavailable이므로 프로젝트 기준을 따른다. 공식 이미지 입력·구조화 응답 문서를 2026-09-30 확인했다.

- https://developers.openai.com/api/docs/guides/images-vision
- https://developers.openai.com/api/docs/guides/structured-outputs

회귀 검사: 통과·수정·재실패·잘못된 형식·조건 훼손·기존 객체 보호·요청 중단·수동 편집·호출 상한·로컬 생성. 실제 브라우저에서 렌더 이미지가 모델 요청에 포함되는지, 텍스트/사진 경로, 수정 뒤 저장·실행 취소·재실행, 모바일 화면을 확인한다. 고정 응답 검증과 실제 외부 모델 호출을 구분한다.

## 진행 상태

- 구현 완료. 앱 텍스트·사진 경로에서 임시 렌더와 시각 검토를 실행하고, 한 번 수정한 결과만 재검토한다. 최종 결과의 화면 맞춤·라벨 위치·실행 취소·저장 일치, 대화 기록, 중단·중복·수동 편집·잠금 보호를 연결했다.
- 모바일 기존 화면이 채팅 결과를 숨기는 문제를 실제 화면에서 확인했다. 이번 검토 상태에서는 결과·중단·초안 이미지·반영 버튼을 보이게 하고 키보드 접근을 확인했다. 큰 화면 개편은 하지 않았다.
- 새 9개 회귀 검사와 전체 499개 검사·정적 빌드가 통과했다. 실제 브라우저 12개 흐름도 통과했고 미처리 브라우저 오류는 0건이다. 검토 호출에 실제 PNG가 포함되고 수정 뒤 PNG가 바뀌며, 함수 화면 맞춤 뒤 최종 PNG가 검토 PNG와 같은 것도 확인했다.
- 로컬 환경에 외부 OpenAI API 키가 없어 고정 제공자 응답으로 검사했다. 외부 모델의 임의 문항 정확도는 미검증이다. 검토에는 호출·대기 시간이 추가되며 생성의 기존 보정 호출과 구분한다. 사용법은 `앱-AI-그림-확인-사용법.md`에 있다.
- 기존 코드 전용 작업 공간과 브랜치를 재사용한다. 로컬·원격 main은 39f6c81, 운영 별칭은 기존 READY 배포다. main 병합과 운영 배포는 이번 범위에 포함하지 않는다.
- 코드 커밋 ab3948b 푸시·Preview READY를 확인했다. Preview는 Vercel 로그인이 필요하므로 익명 앱 실행은 미확인이다. 로컬 화면 http://127.0.0.1:8767 에서 앱과 새 검토 기능의 초기화를 확인했고, 원본 작업 폴더에도 검증본을 안전하게 반영했다. 운영 변경은 없다.
