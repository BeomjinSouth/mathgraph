# 도형 표시와 단원별 작도 기능 확장

## 요구사항

변의 길이를 점선으로 표시하고 같은 각을 표시하는 작업을 화면에서 완결한다. 여러 단원의 도형·그래프 제작에 재사용할 수 있는 평행 표시와 좌표 보조선을 함께 제공한다. 기존 편집 화면과 사용자 저장 좌표는 유지한다.

## 구현 범위

1. 길이 치수: 점선/실선, 값 표시, 곡률 숫자 입력과 방향 뒤집기. 기존 점선 길이 호·텍스트 드래그 유지.
2. 각도: 같은 각 도구, 빗금 수·호 개수·반지름·값 표시 편집. 직각에 가까운 각이 반올림만으로 직각 표시되지 않도록 수정.
3. 도형 관계: 등변 표시의 개수·크기 편집, 평행 화살표 생성·편집·저장. 실제 수직 관계를 확인하는 직각 표시와 한 번의 실행 취소.
4. 좌표와 함수: 점에서 좌표축까지 이어지는 점선 보조선을 추가하고 점 이동을 따라가도록 연결한다.

## 구현 방법과 제약

- 기존 AngleDimension/LengthDimension/EqualLengthMarker를 재사용한다. 평행 표시·좌표 보조선만 독립 객체로 추가한다.
- 새 객체를 ObjectManager 생성/복원, 복사 참조, 도구 등록, 속성 창에 연결한다. 별도 패키지나 API 호출 비용을 추가하지 않는다.
- 기존 UI에 컨트롤을 추가하는 범위이며 화면 재설계는 하지 않는다. 화면 문구는 기능명·입력 라벨·작도 순서만 둔다.
- 원본 폴더의 미커밋 시험지 및 산출물을 보존한다. 전용 worktree/브랜치에서 메인 에이전트만 작성하고 독립 조사는 읽기 전용으로 수행한다.
- 원격 main과 현재 브랜치의 이력이 다르므로 운영 배포는 main 정합성과 반영 권한을 확인하기 전 실행하지 않는다. 기존 시험지 자료가 포함된 이력을 무심코 외부 전송하지 않는다.

## 완료 기준과 검증

- 사용자 도구로 생성 → 속성 수정 → 점 이동 → 실행 취소/다시 실행 → 저장/불러오기 → 내보내기에서 표시가 유지된다.
- 퇴화한 선/각과 잘못된 입력을 처리하며, 표시 편집이 점 위치를 바꾸지 않는다.
- 새 동작의 회귀 검사와 기존 전체 검사를 포함하는 vercel-build를 실행한다.
- 실제 데스크톱·모바일 화면에서 도구, 속성 입력, 점 이동, 저장 복원, PNG/SVG 출력을 확인한다.

## 사용 방법

- 측정 → 길이: 선분이나 다각형의 변을 선택하고 오른쪽에서 치수선·휨·방향·텍스트를 편집한다.
- 측정 → 같은 각: 첫 점→꼭짓점→끝 점 순서로 두 각을 선택한다. 표시를 선택하면 빗금·호 개수·반지름·값 표시를 바꿀 수 있다.
- 측정 → 같은 길이/평행 표시: 선 또는 다각형의 두 변을 선택한다. 표시 개수와 크기를 오른쪽에서 조절한다.
- 측정 → 좌표 보조선: 점을 선택하고 두 축 방향·값·소수 자릿수를 조절한다. 원래 점을 움직이면 보조선이 따라간다.
