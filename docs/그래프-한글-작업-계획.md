# 그래프 편집과 한글 입력 개선

시작: 2026-09-05 21:33 KST. 사용자 승인: 그래프 편집기 직접 조작 및 오류 수정, 디자인 개선, 문제 사진을 읽어 한글 현재 커서 위치에 문제와 그림 입력. 디자인 방향은 흰 작업판·먹색·청록 포인트의 정밀한 편집 도구로 확인했다.

## 제품 요구사항

- 함수·점·선분·원 생성, 좌표/속성 변경, 드래그, 실행 취소, 저장/불러오기를 실제 화면에서 확인하고 발견한 오류를 고친다.
- 그래프를 중심에 두고 장식, 중복 저장 버튼, 항상 보이는 긴 안내를 줄인다. 좁은 화면에서도 캔버스와 필요한 도구를 사용할 수 있어야 한다.
- 사진을 첨부하면 기존 장면 생성과 함께 문제 본문·보기·수식을 구조화한다. 사용자는 인식 결과를 확인하고 수정할 수 있다.
- 한글이 없으면 새 문서를 만든다. 하나면 자동 선택한다. 여러 개면 문서 제목 목록에서 선택한다. 다른 문서나 문서 끝으로 임의 이동하지 않는다.
- 숫자·문자·식·단위는 한글의 편집 가능한 수식 개체로 넣는다. 문제 번호는 텍스트다. 인식이 불확실하면 표시하고, 해결되지 않은 내용은 자동 입력하지 않는다.
- 그림은 현재 편집한 캔버스를 출력용 해상도로 넣는다. 그림 속 수학 라벨은 별도 편집 가능한 수식으로 보존하는 방식을 검토한다.
- 원본 파일을 덮어쓰지 않는다. 연결 실패와 한글 미설치 시 복구 방법을 화면에 안내한다.

## 구현

1. 기존 컴포넌트 구조 위에서 밝은 도구 테마, 상단 작업 동작 정리, 접을 수 있는 보조 패널을 적용한다.
2. 기존 AIService의 인증·시간 제한·모델 설정을 재사용해 문제 인식용 구조화 응답을 받는다. 장면 생성과 문서 인식을 별도 결과로 검증한다.
3. Windows 로컬 연결 프로그램은 loopback에만 바인딩하고 허용 출처·연결 토큰·요청 크기·중복 입력 방지를 적용한다. 임의 코드나 파일 경로를 웹에서 받지 않는다.
4. 한글 COM 작업은 단일 실행 주체에서 순서대로 처리한다. 대상 ID 재검증, 커서 보존, 수식 개체 생성, 그림 삽입을 수행한다.
5. 설치/시작 스크립트와 사용 안내를 제공한다. 추가 서버·DB·월 구독은 만들지 않는다. 사진 분석은 기존 설정의 API 사용 비용이 발생한다.

## 성공 기준과 검증

- Computer Use로 대표 편집 흐름과 한글 연결 화면을 실제 조작한다.
- 핵심 데이터 검증, OCR 오류, 문서 0/1/다수 분기, 인증/출처 제한, 중복 요청에 회귀 테스트를 실행한다.
- 설치된 한글의 별도 시험 문서에서 실제 수식 개체·그림·삽입 위치를 확인한다.
- npm test, vercel-build, git diff --check를 실행하고 데스크톱/모바일 화면을 확인한다.
- 미검증한 실 API/실 문서 조건은 완료 기록에서 구분한다.

## 사용 스킬

routing-personal-playbooks, solo-ai-workbench, pbj-ui-copy, computer-use, hancom-hwpautomation. 파일 산출물 처리에는 hwpx의 열림 검증을 적용한다. UI 목표 이미지는 imagegen을 사용한다.

## 상태

- 이어서 확인한 수식 오류: 한글로 렌더링한 기존 시험 사진에서 `y=-x^2+4`의 `+4`가 지수에 포함되는 것을 확인했다. 지수·첨자 한 항과 분수 전체를 한글 스크립트의 중괄호로 명확히 묶도록 수정했다. Python 테스트 13개와 한글의 실제 9가지 수식 렌더링으로 검증했고 운영 ZIP에 배포했다. 올바르게 렌더링된 완전한 문제 사진을 연속 인식 검증에 사용할 준비를 마쳤으며 인앱 소유자 로그인 대기 중이다.

- 운영 화면 추가 점검: 연결 프로그램이 새 탭을 열면 탭별 로그인 상태가 없어 입력 대화상자가 로그인 화면을 가리는 것을 재현했다. 연결 코드는 보존하고 로그인/바로 그리기 이후 대화상자를 열도록 변경한다. 사진 파일 오류도 열린 입력창 안에서 보이게 하고, 문서 목록 조회 시간 초과를 입력 결과 미확인과 구분한다. 인증 전후 전환과 재시도에 회귀 검증을 추가한다.

- 흰색·먹색·청록 테마와 반응형 도구 패널, 한글 입력 대화상자를 구현했다.
- 직접 조작 중 발견한 서브메뉴 가림, 접힌 도크의 빈 공간, 실행 취소 후 속성 값 불일치, 함수 단축키의 글자 유입, 프로젝트 저장/불러오기 오류를 수정했다.
- 문제 인식·편집·조건/선택지 문단·자동 입력·로컬 연결 프로그램을 구현했다. 그림 라벨도 한글 수식 개체로 분리한다.
- 한글 2024 실측: 새 문서에 수식 26개와 PNG 1개, 기존 커서 사이 삽입, 글자 크기 상속, 다른 시험 문서 보존을 확인했다. 저장 확인창이 열린 경우 한글의 문서 전환 상태와 실제 입력 대상이 달라지는 것을 재현해 창 상태와 대상 재검증을 추가했다. 수정 후 독립된 새 시험 문서에서 2회 연속 통과했다.
- 웹 테스트 413개, Python 테스트 11개 통과. HWPX strict/구조 검사 통과. 추가 수정까지 운영 배포가 Ready이며 대표 페이지와 연결 프로그램 ZIP 다운로드는 HTTP 200이다. 운영 화면의 직접 그리기·함수 생성·초기화와 오류 없는 실행을 확인했다. 배포 주소와 커밋은 진행 기록에 남겼다.
- 실 AI 판독 정확도는 미검증이다. 비밀정보를 복사하지 않고 운영 브라우저에 로그인했으나 자동 업로드 도구가 사진을 0바이트로 전달하고 이후 Chrome 연결이 끊겼다. 키 없음/오류/취소와 모의 구조화 응답을 검증했고, 실제 운영 화면의 한글 연결 및 문서 0개 분기를 확인했다.
