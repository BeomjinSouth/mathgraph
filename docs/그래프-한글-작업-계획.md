# 그래프 편집과 한글 입력 개선

시작: 2026-09-05 21:33 KST. 사용자 승인: 그래프 편집기 직접 조작 및 오류 수정, 디자인 개선, 문제 사진을 읽어 한글 현재 커서 위치에 문제와 그림 입력. 디자인 방향은 흰 작업판·먹색·청록 포인트의 정밀한 편집 도구로 확인했다.

## 제품 요구사항

- 함수·점·선분·원 생성, 좌표/속성 변경, 드래그, 실행 취소, 저장/불러오기를 실제 화면에서 확인하고 발견한 오류를 고친다.
- 그래프를 중심에 두고 장식, 중복 저장 버튼, 항상 보이는 긴 안내를 줄인다. 좁은 화면에서도 캔버스와 필요한 도구를 사용할 수 있어야 한다.
- 사진을 첨부하면 기존 장면 생성과 함께 문제 본문·보기·수식을 구조화한다. 사용자는 인식 결과를 확인하고 수정할 수 있다.
- 한글이 없으면 새 문서를 만든다. 하나면 자동 선택한다. 여러 개면 문서 제목 목록에서 선택한다. 다른 문서나 문서 끝으로 임의 이동하지 않는다.
- 숫자·문자·식·단위는 한글의 편집 가능한 수식 개체로 넣는다. 문제 번호는 텍스트다. 인식이 불확실하면 표시하고, 해결되지 않은 내용은 자동 입력하지 않는다.
- 그림은 현재 편집한 캔버스를 출력용 해상도로 넣는다. 그림 속 수학 라벨은 별도 편집 가능한 수식으로 보존하는 방식을 검토한다.
- 원본 파일을 덮어쓰지 않는다. 연결 실패와 한글 미설치 시 복구 방법을 화면에 안내한다.

## 구현

1. 기존 컴포넌트 구조 위에서 밝은 도구 테마, 상단 작업 동작 정리, 접을 수 있는 보조 패널을 적용한다.
2. 기존 AIService의 인증·시간 제한·모델 설정을 재사용해 문제 인식용 구조화 응답을 받는다. 장면 생성과 문서 인식을 별도 결과로 검증한다.
3. Windows 로컬 연결 프로그램은 loopback에만 바인딩하고 허용 출처·연결 토큰·요청 크기·중복 입력 방지를 적용한다. 임의 코드나 파일 경로를 웹에서 받지 않는다.
4. 한글 COM 작업은 단일 실행 주체에서 순서대로 처리한다. 대상 ID 재검증, 커서 보존, 수식 개체 생성, 그림 삽입을 수행한다.
5. 설치/시작 스크립트와 사용 안내를 제공한다. 추가 서버·DB·월 구독은 만들지 않는다. 사진 분석은 기존 설정의 API 사용 비용이 발생한다.

## 성공 기준과 검증

- Computer Use로 대표 편집 흐름과 한글 연결 화면을 실제 조작한다.
- 핵심 데이터 검증, OCR 오류, 문서 0/1/다수 분기, 인증/출처 제한, 중복 요청에 회귀 테스트를 실행한다.
- 설치된 한글의 별도 시험 문서에서 실제 수식 개체·그림·삽입 위치를 확인한다.
- npm test, vercel-build, git diff --check를 실행하고 데스크톱/모바일 화면을 확인한다.
- 미검증한 실 API/실 문서 조건은 완료 기록에서 구분한다.

## 상태

- 2026-09-07 지필평가 출력 추가 요구: 라벨 선택 범위를 10 mm로 확인한다. 길이 호는 선분의 수직이등분선에 대칭인 곡선으로 만들고, 기본 높이를 위쪽 변의 호 높이에 맞추되 다른 선과 충돌하면 높이를 줄인다. 중앙의 설명선은 실제로 끊고 그 빈 구간 안에 수식 라벨을 고정한다. 평행 기호와 cm 단위 앞뒤의 명시적 공백을 제거한다. 제공한 지필평가 원안지의 스타일·다단·문항 번호·선택지 배치를 분석해 재사용 가능한 문서로 정리한다. 원본은 보존하고 이전 로컬 시험 산출물은 최신 검증본을 남긴 뒤 정리한다. 실제 한글 렌더링, 라벨 이동, 회귀 검사로 검증한다.
- 2026-09-07 수식 라벨 선택 영역 보완: 그림의 `E·D`와 길이 `8·6·10·x`는 이미지 글자가 아니라 글 앞으로 놓인 독립 한글 수식이다. 수식 개체의 바깥 여백만 넓혀도 실제 선택 범위는 넓어지지 않는 것을 한글에서 확인했다. 따라서 수식을 가로·세로 10 mm의 투명 글상자 안에 가운데 정렬해, 보이는 좌표는 유지하면서 상자 전체를 끌어 옮길 수 있게 바꾼다. 상자 안의 수식은 그대로 편집할 수 있다. 실제 마우스로 눌러 끌기 확인은 사용자가 직접 진행한다.
- 2026-09-07 출력 모양 재검증 계획: 사용자가 지적한 점·선분 이름의 기울임, 원본과 다른 평행 기호, 그림의 과도한 여백과 라벨 겹침을 수정한다. 일반 변수의 기울임은 유지하고 정체 범위를 수식 내부에서 한정한다. 원본의 한글 평행 기호를 실제 렌더링으로 대조한다. 그림의 선·점과 라벨을 함께 감싸도록 출력 범위를 자르고, 한글 수식 크기를 고려해 선과 겹치지 않는 라벨 위치를 찾는다. 같은 실제 문항의 수정 전후 한글 출력, 본문·라벨 수식 개수, 원본 보존과 관련 회귀 검사로 검증한다. 통합·푸시·배포는 앞서 요청한 승인 대기 상태를 유지한다.
- 구현·확인 결과: 원본의 한글 평행 글리프와 정체/기울임 복원을 실제 수식 13종으로 대조했다. 실제 문항을 다시 출력해 수식 16개·그림 1개, 정체인 점 이름과 선분, 기울어진 변수, 줄어든 그림 여백과 라벨 간격을 확인했다. 본문의 일반 글자가 요청 내용과 정확히 같은지도 검사했다. 별도 보조 시험 문서는 도중에 활성 문서가 바뀌어 보호 장치가 중단했으며 완료로 세지 않았다. 관련 웹 15개·Python 15개 검사와 로컬 미리보기 확인을 통과했다. 최종 전체 검사 영수증과 운영 반영 상태는 진행 기록에 남긴다.
- 2026-09-07 길이 표시 보완 계획: 사진에서 인식한 선분의 수치·변수 길이 라벨은 일반 글자 대신 점선 호 모양의 길이 치수로 바꾼다. 숫자·분수·근호·소문자 변수만 대상으로 하며, `AB` 같은 선분 이름과 일반 설명은 바꾸지 않는다. 치수선은 도형 중심에서 바깥쪽으로 휘게 하여 본문 도형과 겹침을 줄인다. 동일한 실제 문항의 브라우저 화면과 새 한글 문서에서 점선 호·수식 라벨·원본 보존을 확인한다.
- 진행 결과: 이전 형식과 새 길이 치수 관계 모두를 점선 호로 처리하고, 자동 변환·저장·음수 방향·충돌 없는 배치를 회귀 검사했다. 로컬 화면에서 수동 길이 치수의 실제 점선 호와 값을 확인했다. 이번 변경 뒤 사진 인식부터 한글 입력까지의 연속 확인은 운영 반영 시점에 남긴다.
- 2026-09-07 점 라벨·길이 호 추가 보완 계획: 점 이름으로 쓰인 대문자 알파벳은 한글 수식에서 `rm`으로 고정해 기울이지 않는다. 길이 호의 기본 굽힘을 키워 선분과 분명히 떨어뜨린다. 그림 라벨 수식은 글 앞으로·잠금 해제·겹침 허용 상태로 두고, 배경 그림보다 우선 선택되어 한글에서 직접 끌어 옮길 수 있어야 한다. 같은 실제 문항을 새 문서에 출력해 `E`, `D`, `B`, `C`, `A`의 수식 스크립트와 점선 호 네 개, 실제 드래그 후 위치 변화를 함께 확인한다.
- 진행 결과: 대문자 점 이름을 `\\mathrm{…}`로 전달하고 한글에서는 `{rm …} it`으로 변환하는 회귀 검사를 추가했다. 기본·자동 길이 호의 곡률을 48로 키웠다. 그림은 글 뒤로 두되 다음 문항이 겹치지 않도록 그림 높이만큼 빈 문단을 예약했고, 각 점 라벨은 글 앞으로·잠금 해제 상태로 둔다. 실제 한글에서 `E`를 끌어 옮긴 뒤 상태 표시줄이 그림이 아닌 수식으로 바뀌는 것을 확인했다. 새 파일의 수식 16개, 원본 해시 보존, HWPX 구조·한글 열림을 확인했고 운영 반영은 여전히 승인 대기다.

- 2026-09-07 현재 확인 범위: 실제 기말고사 4번의 본문·선택지 판독과 같은 AI 응답의 로컬 재생을 확인했다. 평행선 참조 오류, 길이 라벨 숨김, 일반 배점 거절을 수정했다. 실제 응답에서 만든 그림 11개 객체, 라벨 9개와 편집 결과를 확인했고, 화면의 데이터를 새 한글 문서에 전달해 수식 16개·그림 1개·원본 보존·실제 열림을 확인했다. 웹 관련 검사 37개와 Python 14개 통과. 자동 승인 검토가 통합·배포 승인을 요구하여 운영 반영은 보류했다. 운영 사진 재인식과 브라우저 버튼에서 한글까지의 연속 검증은 반영 승인 후 남은 항목이다. 아래 미검증 기록은 앞선 시점의 이력이다.

- 2026-09-07 실문항 재현: 사용자가 지정한 한글 파일의 문제 사진에서 본문·선택지 인식은 성공했지만, 모델의 `parallel.refs=[선분, 선분]`을 앱이 `[기준선, 지나는 점]`으로 처리해 그림 적용이 실패했다. 기존 두 선의 관계와 새 선 작도를 구분한다. 기존 선 관계는 불필요한 직선을 추가하지 않고 좌표로 검증하며, 잘못된 점/선 참조는 캔버스 적용 전에 거절한다. 같은 실패 응답의 재생, 평행·수직·불일치·정상 작도 회귀 검증과 실제 문항의 한글 입력으로 확인한다. 원본 시험지와 사진은 로컬 검증 자료로만 보존한다.

- 이어서 확인한 수식 오류: 한글로 렌더링한 기존 시험 사진에서 `y=-x^2+4`의 `+4`가 지수에 포함되는 것을 확인했다. 지수·첨자 한 항과 분수 전체를 한글 스크립트의 중괄호로 명확히 묶도록 수정했다. Python 테스트 13개와 한글의 실제 9가지 수식 렌더링으로 검증했고 운영 ZIP에 배포했다. 올바르게 렌더링된 완전한 문제 사진을 연속 인식 검증에 사용할 준비를 마쳤으며 인앱 소유자 로그인 대기 중이다.

- 운영 화면 추가 점검: 연결 프로그램이 새 탭을 열면 탭별 로그인 상태가 없어 입력 대화상자가 로그인 화면을 가리는 것을 재현했다. 연결 코드는 보존하고 로그인/바로 그리기 이후 대화상자를 열도록 변경한다. 사진 파일 오류도 열린 입력창 안에서 보이게 하고, 문서 목록 조회 시간 초과를 입력 결과 미확인과 구분한다. 인증 전후 전환과 재시도에 회귀 검증을 추가한다.

- 흰색·먹색·청록 테마와 반응형 도구 패널, 한글 입력 대화상자를 구현했다.
- 직접 조작 중 발견한 서브메뉴 가림, 접힌 도크의 빈 공간, 실행 취소 후 속성 값 불일치, 함수 단축키의 글자 유입, 프로젝트 저장/불러오기 오류를 수정했다.
