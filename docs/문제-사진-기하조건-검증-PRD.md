# 문제 사진 기하 조건 검증 PRD

## 목표

문제 사진에서 모델이 같은 길이 표식을 붙였더라도 실제 좌표의 길이가 다른 장면을 성공으로 처리하지 않는다. 조건이 맞지 않으면 최종 도형을 적용하기 전에 재시도를 요청한다.

## 문제와 범위

- 문제 사진 장면의 `equalLengthMarker`는 두 선분을 참조하지만, 기존 검증은 선분 ID 존재 여부만 확인했다.
- 따라서 `AB=AC`, `AD=BC`처럼 서로 다른 길이 조건을 표식만으로 표시하고, 실제 점 좌표는 조건에 맞지 않는 결과가 적용될 수 있었다.
- 이번 작업은 정적 좌표로 계산 가능한 같은 길이 조건을 검사하고, 오류 내용을 재시도 요청에 전달한다.
- 각의 양변을 그리라는 문제 사진 지시도 보강한다. 예를 들어 `∠DBC`가 질문에 있으면 `BD`와 `BC`가 보이도록 한다.

## 제외 범위

- 모델의 비공개 추론 과정을 저장하거나 노출하지 않는다.
- 좌표가 계산 불가능한 자유 드래그 객체와 새 도형 편집 도구는 추가하지 않는다.
- 이미지 원본이나 API 키를 상시 보관하는 진단 로그 기능은 이번 작업에 포함하지 않는다.

## 완료 기준

1. 실제 길이가 다른 두 선분을 같은 길이 표식으로 연결한 장면은 검증에서 거부된다.
2. 동일한 길이의 선분은 허용한다.
3. 거부 오류에는 표식 ID, 두 선분 ID, 실제 길이가 포함되어 재시도 모델이 수정할 근거를 받는다.
4. 문제 사진 장면의 안내문은 구하려는 각의 두 변을 포함하도록 명시한다.
5. 회귀 테스트, 전체 테스트, 정적 빌드, `git diff --check`를 통과한다.

## 검증 경계

- 단위 테스트는 결정적인 좌표 장면과 재시도 요청의 오류 전달을 확인한다.
- 실제 OpenAI 이미지 호출은 비용과 인증이 필요하므로, 별도 인증·비용 승인 없이는 실행하지 않는다.
