# 문제 사진에서 한글까지

## 처음 연결하기

1. MathGraph 상단의 **한글에 넣기**를 누릅니다.
2. **처음 연결하기 → 연결 프로그램 받기**에서 ZIP을 받아 압축을 풉니다.
3. Windows용 한컴오피스 한글과 Python 3.10 이상이 설치된 PC에서 **시작.cmd**를 실행합니다. 첫 실행에만 pywin32를 설치합니다.
4. 자동으로 열린 MathGraph에서 로그인하거나 **바로 그리기**를 선택하면 한글 입력창이 열립니다. 사진 인식은 기존의 소유자 로그인 또는 AI 설정의 API 키를 사용합니다.

## 문제 넣기

- **사진 가져오기**로 문제 전체가 보이는 사진을 선택합니다. 문제 본문·조건·선택지 인식과 편집 가능한 그림 생성을 함께 진행합니다.
- 원본 사진과 미리보기를 비교합니다. **내용 수정**에서 고칠 수 있습니다. 수식은 `$y=x^2$`, `$\frac{1}{2}$`처럼 표시합니다.
- 음수나 여러 항으로 된 지수·첨자는 `$x^{-2}$`, `$a_{n+1}$`처럼 중괄호로 묶습니다.
- 점 이름은 `$\mathrm{A}$`, 선분은 `$\bar{\mathrm{BC}}$`처럼 정체로 씁니다. 대문자 점 이름 위의 막대는 정체로 보완하고, 평행 기호는 학교 수학에서 쓰는 비스듬한 모양으로 출력합니다. 변수의 기울임은 유지합니다.
- 한글 문서가 없으면 새 문서를 만들고, 하나면 자동으로 선택합니다. 여러 개면 파일명과 **현재 문서** 표시를 보고 고릅니다. 파일명이 같으면 폴더 이름도 표시합니다.
- 한글에서 원하는 위치에 커서를 놓고 선택 영역과 저장 대화상자를 해제합니다. **커서 위치에 넣기**를 누르면 그 위치에 추가됩니다.
- 본문은 현재 커서의 글꼴·크기·문단 모양을 따릅니다. 조건·보기에는 테두리가 생깁니다. 두 단 시험지는 그림 폭 **80 mm**, 넓은 본문은 **120 mm**, 활동지는 **150 mm**를 선택합니다.
- 반복 입력은 **다음 사진부터 인식 후 바로 넣기**를 켭니다. 문제 인식과 그림 생성이 모두 성공하고 확인 사항이 없을 때만 자동으로 추가됩니다.

## 편집과 복구

본문·보기·그림의 숫자, 문자, 분수, 근호, 단위는 한글 수식 개체입니다. 문항 번호는 일반 텍스트입니다. 그림의 선과 곡선은 PNG이므로, 모양은 MathGraph에서 수정하고 다시 넣습니다.

사진에서 인식한 선분 길이의 숫자·분수·변수는 선분 위의 일반 라벨 대신 충분히 굽힌 점선 호 길이 표시로 넣습니다. 이 호와 선분은 PNG로, 길이값은 편집 가능한 한글 수식으로 들어갑니다. 직접 그린 선분에서는 **측정 → 길이**를 선택한 뒤 선분을 클릭해 같은 표시를 추가할 수 있습니다.

그림 속 대문자 점 이름은 `rm` 수식으로 넣어 기울이지 않습니다. 점 이름을 한 번 눌러 수식 개체가 선택되면 그대로 끌어 위치를 바꿀 수 있습니다. 그림은 배경에 두므로 점 이름을 누를 때 그림이 먼저 선택되지 않습니다.

프로젝트 저장은 문제 본문과 편집 가능한 도형을 함께 보관합니다. 사진 원본과 API 키, 한글 연결 코드는 프로젝트 파일에 포함하지 않습니다.

한글 입력을 되돌릴 때는 한글의 실행 취소를 사용합니다. 기존 한글 문서를 자동 저장하거나 닫지 않습니다. 입력 결과가 불분명하면 **결과 다시 확인**을 눌러 같은 요청의 결과를 확인합니다. 연결 프로그램을 재시작하기 전에는 한글에 이미 들어갔는지 먼저 확인합니다.

회전된 그림 라벨, 지원하지 않는 LaTeX 명령, 읽기 전용 문서, 선택 영역, 열린 확인창은 입력 전에 안내합니다. 임의의 수식 양식·복잡한 표·행렬·경우 나누기와 손글씨 인식은 별도 검증이 필요합니다. 그림은 현재 작업판에서 보이는 도형과 라벨 주위의 빈 여백을 잘라 저장합니다. 한글 수식이 선과 겹치지 않도록 가까운 빈자리로 옮기며, 놓을 자리가 없으면 위치를 조정하도록 안내합니다. 좌표축이 필요 없는 도형은 **좌표축 포함**을 끄고, 문서의 단 너비에 맞춰 그림 폭을 선택합니다.

## 검증 범위

2026-09-06, 한컴오피스 한글 2024와 Python 3.12에서 새 문서 생성, 기존 커서 삽입, 여러 문서 선택, 다른 시험 문서 보존, 글자 크기 상속, 네이티브 수식·그림 삽입을 확인했습니다. 수식 26개·그림 1개의 시험 결과는 HWPX 구조 검사와 한글 화면 확인을 통과했습니다.

이후 지수 뒤의 덧셈까지 지수로 표시되는 오류를 추가로 발견해 수정했습니다. 지수·첨자·분수 전체의 범위를 명시적으로 묶고, 새 한글 문서에서 9가지 수식이 의도한 모양인지 확인했습니다. 이전 연결 프로그램을 받았다면 최신 ZIP을 다시 받아 실행해 주세요.

2026-09-07에는 실제 문항 한 개의 본문·선택지 판독과 같은 응답의 도형 재생을 확인했습니다. 브라우저가 내보낸 문항을 새 한글 문서에 입력해 수식 16개·그림 1개를 확인했고, 정체·평행 기호·라벨 간격·그림 여백을 실제 한글 출력으로 다시 확인했습니다. 이후 점 이름 `E`를 실제 한글 화면에서 수식 개체로 선택해 끌어 옮겼고, `E·D·B·C·A`가 모두 `rm` 수식으로 저장된 것도 확인했습니다. 이 수정은 로컬 검증 상태이며 운영 반영 승인을 기다리고 있습니다. 운영 화면에서 수정 후 사진을 다시 인식하는 과정과 브라우저 입력 버튼에서 한글까지의 연속 검증은 남아 있습니다.
