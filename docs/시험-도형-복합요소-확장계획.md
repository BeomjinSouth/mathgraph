# 시험 도형 복합 요소와 함수 영역 반복 검수

## 목표와 범위

교사가 다듬은 24종의 배치 기준과 기존 100종 검사를 유지하면서, 여러 조건이 동시에 있는 도형과 함수 그래프의 시험용 표시를 실제 렌더에서 검증한다. 새 사례는 교사 승인 사례가 아닌 검사용 합성 자료로 구분한다. 사용자 HWPX와 원본 그림은 수정하지 않는다.

## 확인할 요소

- 길이 값과 곡선형 점선 치수선, 각도 값과 호, 같은 각의 표시 개수, 독립적인 같은 길이 표시 개수
- 꼭짓점·교점의 이름과 선·호·다른 글자 사이 간격, 숨겨야 할 계산용 점과 보조선
- 각기둥·각뿔의 앞면 실선과 가려진 모서리 점선, 꼭짓점 표식 중복 여부
- 일차·이차·구간별·비선형 함수와 좌표축 사이 또는 두 함수 사이에서 넓이를 구하도록 지정한 영역의 실제 음영과 경계
- 좌표·교점·길이·각 등 수학 조건, 저장·불러오기·PNG 출력의 일치

## 구현과 검증 순서

1. 기존 100종이 다루는 범위와 놓친 조합을 목록화한다. 새 사례의 문항 조건, 참조 좌표, 음영 경계와 보이는 선 종류를 독립적인 기대값으로 기록한다.
2. 함수 곡선으로 둘러싸인 넓이에는 `functionRegion` 객체를 추가한다. 두 함수 또는 한 함수와 수평 기준선, 닫힌 x구간을 입력으로 받고 캔버스 해상도에 맞춰 경계를 그린다. 함수의 정의역 밖이나 비유한 값이 있는 구간은 유효한 음영으로 취급하지 않는다. 저장·불러오기, AI 생성 스키마와 문항 추출 경로를 함께 연결한다.
3. 동일 입력으로 최초 렌더와 검사를 남긴다. 조건 누락, 표시 위치, 영역 오류를 사례 설계 오류와 공통 렌더·생성 오류로 나눈다.
4. 공통 원인을 고치고 새 사례를 반복 렌더한다. 일부 유형의 변형은 마지막 확인용으로 분리한다. 실패한 중간 결과를 보존한다.
5. 자동 검사의 판단 범위를 실제 픽셀과 객체 상태로 교차 확인한다. 모든 모아보기 그림을 눈으로 살펴 자동 검사 사각지대를 보완한다. 대표 사례는 앱 불러오기·수정 취소·재실행·저장 왕복을 확인한다.
6. 관련 회귀 검사와 빌드를 실행하고 결과·남은 한계를 기록한다. HWP 인쇄 규격은 현재 캔버스 검수와 구분한다.
7. 실제 모델을 부를 수 없는 환경에서도 범위와 함수식이 명확한 넓이 요청은 한 번의 자연어 명령으로 두 함수와 음영까지 만들 수 있는지 검사한다. 지원하지 않는 모호한 요청은 임의의 구간·경계를 추측하지 않고 오류로 남긴다.
8. 빈 캔버스의 기본 배율에서 넓이 그림이 너무 작으면 음영과 좌표축이 함께 화면에 들어오도록 첫 생성 시에만 화면 배율과 중심을 맞춘다. 사용자가 이미 배율·이동을 바꾼 화면이나 기존 객체가 있는 문서는 유지한다.
9. 실제 자연어 요청에서 복합 평면도형의 조건 누락을 확인한다. `AB=AC`, `∠B=∠C`, 밑변 길이와 꼭지각이 함께 있는 삼각형, 두 독립 길이 그룹과 맞은각이 있는 평행사변형을 우선 지원한다. 좌표에서 실제 길이·각이 맞고 표식·치수선이 모두 생성되어야 한다. 지원하지 않는 복합 조건은 맨몸 도형만 만든 뒤 성공했다고 하지 않는다.
10. 입체도형의 이름·치수·숨은선과 함수의 부가 요청을 함께 넣어 실제 폴백 경로를 재검사한다. 치수를 버린 입체도형이나 접선을 빠뜨린 함수 그림을 성공으로 반환하는 원인을 고친다. 지원하는 추가 패턴은 좌표·렌더·저장 왕복으로 확인하고, 표현하지 못하는 조건은 명시적으로 거부한다.
11. 함수의 색칠 영역과 접선을 함께 요청할 때에는 접선 대상 함수와 x좌표가 명시된 경우에만 한 배치로 만든다. 두 함수 중 접선 대상이 불명확하거나 접점이 색칠 구간 밖·정의역 밖이면 추측하지 않는다.
12. 원기둥의 반지름과 높이가 모두 수치로 주어진 문장을 검사한다. 타원 투영에서 윗면·아랫면 중심의 세로 간격이 요구 높이가 되도록 본체 치수를 계산하고, 반지름 선분·두 점선 치수 호·뒤쪽 밑면 점선을 함께 만든다. 다른 조건은 놓친 채 성공시키지 않는다.
13. 밑면 `AB`와 꼭짓점 `V`가 지정된 사각뿔의 수치 높이를 검사한다. 밑면을 교과서식 사선 도식으로 그리고, 꼭짓점을 밑면 중심의 화면상 수직 위에 놓아 높이선 자체의 길이가 수치와 같게 한다. 숨긴 밑면 중심점·점선 높이선·점선 치수 호를 연결한다. 가려진 모서리의 점선·실선과 높이선·라벨의 구별을 실제 그림으로 확인한다.
14. 원의 반지름·중심각과 부채꼴 또는 호가 함께 지정된 문장을 실제 원샷 경로에서 검사한다. 반지름 선분의 길이, 각도 호의 실제 크기와 표기, 색칠된 부채꼴의 안팎 픽셀, 호의 시작·끝점 이름을 확인한다. 일부만 그린 원을 성공으로 처리하지 않는다.
15. 원의 반지름이 작으면 이름점·각도 호가 겹치고 크면 원·라벨이 캔버스 밖으로 나갈 수 있다. 빈 기본 캔버스에 처음 만든 원·부채꼴·호만 안전 여백을 남겨 화면에 맞추되, 교사가 이미 확대·이동했거나 다른 객체가 있는 화면은 유지한다.

## 완료 기준

- 위 요소별로 적어도 하나의 새 복합 사례와 예상 실패 검사를 갖추고, 새 사례 모두 수학 조건·렌더·왕복 검사를 통과한다.
- 실제 음영이 문항에서 요구한 경계 안에 있는지 픽셀과 좌표로 확인한다. 단순히 `fillOpacity` 값이 존재한다는 이유만으로 통과시키지 않는다.
- 기존 100종과 관련 테스트의 결과가 악화되지 않는다. 사용자가 직접 조정한 위치는 유지된다.
- 앱에서 실제로 생성·편집·출력하는 경로와 검사용 경로의 차이를 기록한다.

## 사용 기준

`mathgraph-drawing`의 스키마와 교사 수정 기준, `pbj-exam-hwpx`의 시험 그림 인쇄 기준을 참고한다. 개인 플레이북 라우터는 현재 `unavailable`이므로 일반 기준과 프로젝트 지침을 적용한다.
