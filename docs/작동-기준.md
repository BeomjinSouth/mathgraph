# 작동 기준

한 작업·한 worktree·한 쓰기 주체(codex)로 진행한다. 작업 ID는 사진-한글-연속확인-20260909-20260909-8fa3이며 기준은 codex/ai-fallback-recovery다.

작업 목표와 범위는 그래프-한글-작업-계획.md를 따른다. 운영 MathGraph에서 문제 사진을 실제로 인식하고, 새 한글 문서에 본문·수식·그림을 입력해 결과를 확인한다. 원본 시험지와 사용자가 연 한글 문서는 바꾸지 않는다. 운영 배포와 main 브랜치는 바꾸지 않는다. 복구 지점은 작업 시작 커밋 72c067c다.

자동 테스트·빌드·공백 검사와 실제 브라우저/한글 확인을 구분해 기록한다. 검증 전 통합하거나 배포하지 않는다. 푸시·배포는 프로젝트 AGENTS.md의 계약을 따른다.
