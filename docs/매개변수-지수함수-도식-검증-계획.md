# 매개변수 지수함수 문제 도식 검증 계획

## 목표

그림이 없는 함수 문제 사진에서도 본문에 명시된 좌표 관계만 추출하여 두 함수, 매개변수 직선, 교점, 수직 보조선이 있는 편집 가능한 시험지용 그래프를 만든다. 문제를 풀거나 극한값을 표시하지 않는다.

## 문제에서 추출할 장면

- 두 곡선은 `y=e^(2x)-e^(-x)+1`, `y=e^(2x)`이다.
- 양수 `t`에 대한 수평선 `y=t`가 첫 번째 곡선과 만나는 점을 `P`, 두 번째 곡선과 만나는 점을 `Q`로 둔다.
- `P`를 지나는 수직선은 두 번째 곡선과 만나며 그 점의 높이가 `f(t)`이다.
- `Q`를 지나는 수직선은 첫 번째 곡선과 만나며 그 점의 높이가 `g(t)`이다.
- 극한의 기준값 `t=1`에서는 `P=Q=(0,1)`로 겹치므로 그림용 대표값으로 사용하지 않는다.

## 대표 장면의 수학값

시각적으로 관계가 분리되는 양수 `t=0.2`를 대표값으로 사용한다.

- `x_P=-0.29957217499230904`, `P=(x_P,0.2)`
- `x_Q=0.5 ln(0.2)=-0.8047189562170501`, `Q=(x_Q,0.2)`
- `f(0.2)=e^(2x_P)=0.5492814277388435`
- `g(0.2)=0.2-e^(-x_Q)+1=-1.0360679774997896`

표시용 소수 좌표는 충분한 정밀도로 저장하되, 테스트에서는 각 점이 실제 함수식과 수직 관계를 만족하는지 허용오차로 검산한다.

## 일반화 규칙

- 매개변수 값이 정해지지 않은 문제는 조건을 만족하는 대표값을 선택할 수 있다.
- 극한값, 경계값, 특수값을 선택했을 때 이름 붙은 점이나 보조선이 겹치면 다른 비퇴화 대표값을 고른다.
- 대표값은 문제 조건을 설명하기 위한 배치일 뿐 정답이나 풀이로 제시하지 않는다.
- 주어진 함수식과 교점·수직·수평 관계는 좌표 검산을 통과해야 한다.
- 문제 본문과 최종 극한값은 그림에 복사하지 않는다.

## 영향 범위

- `js/ai/AIService.js`의 문제 상황·문제 도식 안내
- `mathgraph-drawing` 스킬과 런타임 참고 자료
- 지수함수 대표 장면 합성 예시와 회귀 테스트
- `docs/progress-log.md`

## 완료 기준

- 구현 전 회귀 테스트가 새 규칙 또는 예시 부재로 실패한다.
- 구현 후 합성 예시가 GraphA 스키마를 통과하고 네 교점 좌표와 두 수직선의 관계가 수학적으로 맞는다.
- 최신 로컬 앱에서 두 곡선, `y=t`, `P`, `Q`, 수직선 두 개, `f(t)`, `g(t)` 안내가 겹치지 않고 보인다.
- 전체 테스트, 정적 빌드, 참고 JSON·JSONL 검사, `git diff --check`가 통과한다.
- 실제 OpenAI 이미지 업로드를 실행하지 못하면 브라우저 JSON 렌더링과 프롬프트·스키마 테스트를 구분하여 기록한다.


## 완료 결과

- 사진만 첨부한 요청은 `problem_diagram` 모드로 보내며, 문제 본문에 인쇄된 그림이 없어도 도식 생성 요청으로 처리한다.
- 첫 응답이나 교정 응답이 빈 연산 또는 잘못된 JSON이면 이전 응답과 연결하지 않은 새 이미지 분석으로 한 번 더 복구한다.
- 운영 사이트에서 원본 문제 사진만 첨부하여 `23 created`, `객체 23개`, `문제그림 모드로 생성됨 · 모델: gpt-5.4-mini`를 확인했다.
- 운영 생성 결과는 대표값 `t=2`를 선택했다. `P≈(0.28,2)`, `Q≈(0.35,2)`, `f(t)≈1.75`, `g(t)≈2.29`로 두 곡선과 두 수직선의 관계가 수학적으로 맞았다.
- 대표 장면 테스트는 다른 유효한 값인 `t=0.2`를 사용한다. 특정 출력 좌표를 외우게 하지 않고 비퇴화 대표값 선택과 함수 관계를 검증하기 위한 구분이다.

## 최종 상태: 완료

- 사진만 첨부한 운영 흐름에서 매개변수 지수함수 관계를 추출하고, 비퇴화 대표값으로 편집 가능한 도식을 생성했다.
- 같은 관계가 AI 응답에서 빠지면 원본 이미지로 `sourceBindings`만 다시 추출하는 복구 경로를 적용했다.
- 정사각뿔·타원·포물선과 원·넓이·평행선·조각함수 등 이전 사진도 운영 사이트에서 회귀 확인했다.
- 최종 전체 테스트는 364/364가 통과했고 운영 별칭에 배포했다.
- 남은 위험은 외부 모델 응답 시간이 120초를 넘을 수 있다는 점이다. 실제로 한 번 시간 초과가 있었고 재시도에서는 성공했다.
