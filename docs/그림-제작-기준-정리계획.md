# 그림 제작 기준과 실행 경로 정리

## 목표와 범위

2026-10-07 요청에 따라 이 작업에서 확정한 기준과 검증된 생성 경로를 다음 그림 제작에서 자동으로 찾게 한다. 새 그림을 다시 만들거나 유료 API를 호출하지 않는다. 원본 dirty 폴더, 교사 그림, 시험지, 기존 브랜치와 운영 사이트는 보존한다.

## 정리할 내용

1. 교사 수정 24종에서 확인한 공통 기준과 이후 길이·각·화살표·함수식·같음 눈금 피드백을 짧은 공통 참조로 묶는다. 앱 화면 px와 한글 인쇄 pt/mm는 서로 대체하지 않는다.
2. MathGraph의 AGENTS.md·그림 스킬·앱 배포 참조에서 공통 기준을 읽게 연결한다. 실제 구현 상세는 기존 치수 사용법과 AnnotationGuide에 남긴다.
3. PBJ 시험지 제작의 정본 지침과 수학 폴더의 진입 문서에서도 같은 기준을 찾게 한다. 시험지의 고정 내보내기 엔진을 최신 앱 checkout으로 무조건 바꾸지 않는다. 엔진별 지원 기능과 검사 경로를 구분한다.
4. 기존 100/45종 회귀, 실제 Astra 6종과 독립 조건 45개, 마지막 고정 응답 재생, 교사 승인과 미검증 범위를 구별해 기록한다. 실제 응답·실패·개인 그림은 로컬 증거로 보존한다.

## 완료 기준과 검증

- 다음 MathGraph 및 PBJ 그림 작업의 진입점에서 확정 기준을 찾을 수 있다.
- 새 공통 참조와 앱 배포용 참조는 동일하며 기존 API·지원 객체·교사 수동 배치를 바꾸지 않는다.
- 정본과 설치본의 읽기 경로를 확인하고, 연결되지 않은 부분을 완료했다고 하지 않는다.
- 변경 비교·참조 경로·스킬 형식·기존 참조 동등성 검사와 프로젝트 필수 검사로 확인한다. 추가 외부 모델 호출과 한글 전체 문서 출력은 하지 않는다.
- 최종 코드/문서를 작업 브랜치에 저장·전송한다. main 통합·운영 반영·원본 변경 삭제는 하지 않는다.

## 진행

- 최신 앱 작업 공간은 5d64709이며 깨끗한 상태를 확인했다. 수학 폴더의 옛 MathGraph 작업 공간은 별도 브랜치다. PBJ 제작 정본은 이미 플러그인 내부의 고정 내보내기 런타임을 사용한다. 옛 작업 공간 경로를 고정 엔진의 현재 기본값이라고 다시 기록하지 않는다.
- 개인 플레이북과 공통 관리 스킬은 현재 조회되지 않는다. 프로젝트 규칙과 기존 관리 CLI의 작성자·검증 기록을 사용한다. 새 기억은 저장하지 않는다.

## 결과

- 공통 기준 한 파일, MathGraph의 시작 안내·그림 스킬·AGENTS.md·배포 참조와 원본/수학 진입점, PBJ 그림/시험지 스킬과 설치본을 연결했다. 새 의미를 개인 기억이나 범용 규칙으로 확장하지 않았다.
- 앱 배포용 상세 검수 참조 누락을 발견해 추가하고 참조 동등성 검사에 포함했다. 전체 676개 검사·정적 빌드·공백, PBJ 시험지 도구 50개·실행 연결 5개, 설치 후 경로/보존 검사 11개가 통과했다. 공식 스킬 형식 검사는 PyYAML 부재로 실패했고 별도 앞부분/링크 검사를 수행했다.
- PBJ 커밋 72b95cc와 새 Codex 설치 버전 0.1.0+codex.20261007004856을 확인했다. 기존 PBJ 미커밋 두 문서, 원본 MathGraph의 코드/개인 자료와 기존 엔진은 보존했다. 외부 모델 호출·한글 전체 출력·운영 반영은 이번 정리 범위가 아니다.
- 마지막 관리 검증·전송·Preview 결과는 같은 코드/문서 커밋의 관리 기록에 남긴다. 새 기준을 쓰는 것과 모든 엔진의 자동 구현·인쇄 검증을 완료한 것을 구별한다.
