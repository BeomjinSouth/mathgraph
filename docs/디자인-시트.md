# 그래프 작업 화면 디자인 시트

근거: Design.md, Soul.md, 그래프-한글-작업-계획.md. 사용자가 정밀한 편집 도구 방향을 선택했다.

상단에는 프로젝트 이름, 실행 취소/다시 실행, 파일 열기/저장, 내보내기, 한글 입력을 둔다. 중앙의 넓은 흰 작업판에는 실제 그래프가 보인다. 왼쪽은 도구, 오른쪽은 선택한 도형의 속성이다. 사진·문제 작업은 필요할 때 열 수 있다.

빈 화면에는 한 줄의 시작 안내만 표시한다. 인식 중에는 진행 상태와 취소를 표시한다. 결과에는 본문·보기·식과 그림을 확인할 수 있는 편집란을 둔다. 실패 시 입력 자료를 보존하고 다시 시도할 수 있다. 한글 연결 상태와 대상 문서는 입력 버튼 가까이에 표시한다.

색: 배경 #f3f5f4, 표면 #ffffff, 본문 #202a28, 보조 #69746f, 경계 #dce2de, 강조 #167567. 버튼은 단색이며 주요 행동만 청록으로 강조한다. 아이콘은 기존 SVG를 쓴다.

글자 크기: 본문·라벨·입력·보조 안내는 16pt, 소제목은 17pt, 패널 제목은 18pt, 주요 제목은 20pt로 단계화한다. 20pt를 넘기지 않으며, 상단 `MathGraph` 로고 글자는 기존 크기를 유지한다. 한국어 문장은 어절 단위로 줄바꿈하고, 큰 글자에 맞춰 버튼과 패널의 세로 배치·여백을 조정하되 가로 폭과 작업판은 최대한 유지한다.

데스크톱 1440×900·1280×720과 모바일 390×844에서 넘침·글자 대비·패널 토글·포커스·대화상자를 확인한다. 16:9 단일 실제 작업 화면을 목표 이미지로 만들고 구현 화면과 비교한다.
