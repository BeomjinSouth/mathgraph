# 중·고등 수학 그림 지원 범위와 검증

## 지원 범위

이 문서는 모든 자연어 문항의 성공률을 보장하는 목록이 아니다. 객체가 제공하는 기능, 로컬에서 해석하는 요청, 실제 검증 사례를 구분한다. 원본 그림이나 수학 조건을 변경하여 검사만 통과시키지 않는다.

| 그림 분야 | 현재 경로 | 이번 작업 |
|---|---|---|
| 수직선·실수·구간 | 수직선, 눈금, 열린 점·닫힌 점 | 기존 유지 |
| 삼각형·사각형·다각형 | 점·선·다각형, 평행·수직·중점·교점, 같음 표식·길이·각도 | 기존 복합 그림 회귀 검증 |
| 원·부채꼴·활꼴·렌즈 | 원·호·접선·교집합 음영 | 고리 부채꼴의 실제 구멍 추가 |
| 일차·이차·다항·유리·무리·지수·로그·삼각함수 | 함수식 파서와 범위, 구간별 함수·접선·함수 사이 음영 | 기존 구간별 함수 앱 검증 재사용 |

| 벡터·좌표기하 | 벡터, 점, 선분, 교점, 수치 좌표 | 기존 유지 |
| 각기둥·각뿔·원기둥·원뿔·구 | 교과서식 투영·숨은선·단면 다각형 | 기존 입체 회귀 검증 |

## 바로 입력할 수 있는 예

```text
막대그래프 항목 [월, 화, 수, 목] 자료 [3, 5, 0, 2]
원그래프 항목 [가, 나, 다] 자료 [2, 3, 5]
히스토그램 계급 경계 [0, 5, 15, 30] 도수 [5, 10, 15]
도수분포다각형 경계 [0, 10, 20, 30] 도수 [2, 5, 3]
상자그림 다섯 수치 [2, 4, 6, 8, 11]
점도표 자료 [1, 1, 2, 3, 3, 3, 4]
산점도 (-1, 2), (2, -3), (4, 1)
중심 (5, 6)에 고리 부채꼴 바깥 반지름 4 안쪽 반지름 2 중심각 90
직육면체 전개도 가로 2 세로 3 높이 4 치수를 모두 표시해줘
반지름 3 높이 4인 원뿔 전개도
밑면 한 변 2 높이 4인 정삼각기둥 전개도
밑면 한 변 3 옆면 높이 4인 정사각뿔 전개도
세 집합의 벤 다이어그램 A∩(B∪C)를 색칠해줘
벤 다이어그램 (A∪B)의 여집합을 색칠해줘
평균 0 표준편차 1인 정규분포 -1<=x<=1을 색칠해줘
이항분포 B(10, 1/2)
```

그림을 선택하면 속성 창에서 자료·치수·집합식을 수정할 수 있다. 자료 개수와 계급 경계는 한 번에 적용하므로 중간에 잘못된 그림으로 바뀌지 않는다. 잘못된 값은 오류를 표시하고 원래 그림을 보존한다. 새 객체는 이동, 다중 선택 이동, 실행 취소, JSON 저장·불러오기, PNG·SVG 내보내기에 연결되어 있다.

## 해석과 수학적 제한

- 상자그림은 `[최소, Q1, 중앙, Q3, 최대]`를 받는다. 원자료의 사분위수 계산 관례를 임의로 선택하지 않는다.
- 원뿔의 객체 `height`는 모선 길이이고 정각뿔은 옆면 높이다. 한국어 원뿔 요청이 반지름과 수직 높이를 주면 피타고라스 정리로 모선을 계산한다. 세 치수가 모순되면 거부한다.
- 벤 다이어그램은 서로 겹치는 2~3집합의 논리 영역을 그린다. 포함관계·서로소 배치 등은 이 전용 경로에서 지원하지 않는다. 복잡한 자연어 집합 연산은 `음영식: A∩(!B)`처럼 쓰는 것이 명확하다.
- 자료 배열은 최대 200개, 정규분포는 양수 표준편차와 유한한 음영 구간, 로컬 이항분포는 시행 횟수 1~100을 지원한다. 확률분포 자료를 직접 고칠 때에는 각 값 0~1·합계 1을 검사하고 기존 이항분포 이름을 지운다.
- 로컬 경로에서 서로 다른 그림을 한 문장에 함께 요청하면 일부만 만들지 않고 분리 입력을 안내한다. 임의 문항의 모든 조건을 증명하는 범용 해석기는 아니다.
- 구의 정확한 평면 전개도, 임의 다면체 전개도, 회전체의 연속 회전·3차원 조작, 기호식 적분, 일반 표의 재현은 이번 구현 범위에 포함하지 않는다.
- 함수 음영과 정규분포 곡선은 화면 표시를 위한 표본 곡선이다. 그림 자체를 정확한 넓이나 확률의 계산 결과로 사용하지 않는다.


- 신규 앱 검증: 43개 한국어 요청을 AIService → 실제 앱 적용 → 렌더 → JSON 저장·불러오기 → 실행 취소·재실행 → SVG 경로까지 확인했다. 속성의 정상/오류 적용과 390×844 모바일 입력 버튼 경로도 검사한다.
- 벤 다이어그램은 각 사례당 150개 이상의 화면 픽셀을 독립적인 참/거짓 표와 비교한다. 고리 가운데의 비음영 픽셀도 확인한다.
- 기존 복합 도형 45종·15개 분야에서 실패 0건, 콘솔 오류 0건이었다. 기존 원샷·구간별 함수·치수 수정 검증도 포함했다. 교사가 승인한 임의 문항 전체의 성공률로 해석하지 않는다.
- 자동 검사 중 발견해 수정한 문제: 원뿔 치수 모순, 중심 좌표 누락, 전개도 치수 표시 누락, 복합 요청 부분 성공, B-A 순서 반전, A의 여집합 누락, 집합 포함관계의 잘못된 배치, 확률 편집의 범위·합계 오류, 지수 표기 앞부분만 읽기, 산점도 눈금 겹침, 생성 시각의 저장 왕복 차이, 다중 선택 이동 누락.
- Browser 전용 스킬은 세션에 없어서 기존 Playwright/Chrome을 사용했다. 데스크톱은 1440×1000, 모바일은 390×844로 확인한다.
- 검증은 로컬 생성기와 실제 렌더 및 고정된 모델 응답을 사용했다. 외부 OpenAI/Gemini API의 대량 생성 성공률이나 사진 인식 성능을 측정하지 않았다.
- OpenAI 출력 스키마는 모든 속성 required·선택값 null·additionalProperties:false 계약을 유지했다. [공식 Structured Outputs 문서](https://developers.openai.com/api/docs/guides/structured-outputs)를 2026-09-29에 확인했다. 모델과 API 인증 설정은 변경하지 않았다.
