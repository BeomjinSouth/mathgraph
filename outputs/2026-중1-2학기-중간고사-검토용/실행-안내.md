# 재실행 안내

이 폴더의 `제작.py`는 현행 `pbj-exam-hwpx` 스킬의 원안지 복제·한글 수식·문항 자동 번호 도구를 사용한다. 기존 파일을 덮어쓰지 않으므로 매번 새 `--output` 폴더를 지정한다.

```powershell
$py = 'C:\Users\pbj95\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $py -B .\제작.py --preflight
& $py -B .\제작.py --build --output .\재실행-결과
```

생성 뒤에는 다음 순서로 실제 한글 검증을 다시 해야 한다.

1. 학생용·교사용 HWPX에 strict 구조 검사를 실행한다.
2. `native_verify.py`로 한글에서 직접 PDF를 저장하고 수식 편집·본문 흐름·종료를 확인한다.
3. 모든 PDF 쪽과 문항을 검토하고, 학생용만 먼저 푼 별도 검토 결과를 만든다.
4. `delivery_check.py`를 학생용과 교사용에 각각 실행한다.

이 폴더의 MathGraph 원본과 내보내기는 실제 앱 엔진으로 생성했다. 통계 히스토그램은 MathGraph의 정식 1급 객체가 아니므로, 통계 문항은 표 자료를 읽어 판단하도록 구성했다.
